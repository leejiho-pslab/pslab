### 0-B. (권장·자동 갱신) 네이버 검색광고 API 연동 — ADR-0005 방식

CSV 없이 매주 금요일 자동으로 월간검색수·연관어를 수집해 '차주 콘텐츠 기획'까지 이어집니다.

1. 접속: https://manage.searchad.naver.com → 도구 > **API 사용 관리** → [API 라이선스 생성]
2. 발급된 값 3개를 Secrets에 등록:
```
이름: NAVER_AD_API_KEY      값: (액세스라이선스)
이름: NAVER_AD_SECRET       값: (비밀키)
이름: NAVER_AD_CUSTOMER_ID  값: 2006250  (광고주센터 주소의 ad-accounts 뒤 숫자)
```
3. 이후 흐름(자동): 금요일 키워드 수집 → 토요일 차주 기획(week-plan.json) → 대시보드 '📅 차주 콘텐츠 기획' 패널 표시 → 검수 후 제작.

## 1. 대구일색 전용 저장소 (지금 바로, 5분)

왜: 채널 토큰(시크릿)이 저장소당 1세트라 기존 업체와 같은 저장소를 쓰면 계정이 충돌합니다. 무료 Pages는 **Public 저장소만** 지원됩니다(시크릿은 Public이어도 안전).

1. 접속: https://github.com/new
2. 아래처럼 입력 후 [Create repository]:

```
Repository name: daeguis-sns
Public 선택 (Private면 대시보드 주소가 404)
Add a README: 체크 안 함
```

3. 만든 뒤 저에게 "daeguis-sns 저장소 추가해줘"라고 말씀해 주세요 → 제가 시스템 전체를 이전·셋업합니다.
4. 이후 모든 시크릿 등록 위치: `https://github.com/leejiho-pslab/daeguis-sns/settings/secrets/actions`

## 2. 텔레그램 알림 봇 (지금 바로)

발행 성공/실패·토큰 만료 경보를 폰으로 받습니다.

1. 텔레그램에서 https://t.me/BotFather 열기 → 대화창에 입력:
```
/newbot
```
2. 봇 이름/아이디를 물으면 예시:
```
대구일색 SNS 알림
daeguis_sns_bot
```
3. BotFather가 주는 `123456:ABC-...` 형태 토큰 복사 → Secrets에 등록:
```
이름: TELEGRAM_BOT_TOKEN
값: (BotFather가 준 토큰)
```
4. 방금 만든 봇과 대화 시작(아무 메시지 전송) 후, 브라우저에서 열기:
```
https://api.telegram.org/bot<토큰>/getUpdates
```
   응답의 `"chat":{"id":숫자}` 숫자 복사 → 등록:
```
이름: TELEGRAM_CHAT_ID
값: (chat id 숫자)
```

## 4. 인스타그램 + 스레드 (계정 수령 후)

준비물: 대구일색 **인스타그램 계정**(반드시 앱에서 '프로페셔널/비즈니스 계정'으로 전환 + 공개 계정) + 연결된 **페이스북 페이지** + 스레드 프로필.

1. Meta 개발자 접속: https://developers.facebook.com/apps → [앱 만들기] → 유형 '비즈니스'
```
앱 이름: daeguis-sns
```
2. 앱에 제품 추가: **Instagram Graph API** 와 **Threads API**
3. 그래프 API 탐색기(https://developers.facebook.com/tools/explorer)에서 아래 권한 체크 후 토큰 생성:
```
instagram_basic
instagram_content_publish
pages_show_list
pages_read_engagement
```
4. 장기(60일) 토큰으로 교환: https://developers.facebook.com/tools/debug/accesstoken → [Extend Access Token]
5. IG 사용자 ID 확인 — 탐색기 주소창에 입력:
```
me/accounts?fields=instagram_business_account
```
   응답의 `instagram_business_account.id` 숫자를 복사.
6. Secrets 등록 (4개):
```
이름: PSLAB_INSTAGRAM_ACCESS_TOKEN   값: (장기 토큰)
이름: PSLAB_INSTAGRAM_IG_USER_ID    값: (5번의 숫자 ID)
이름: PSLAB_FB_APP_ID               값: (앱 대시보드의 앱 ID — 만료 경보용, 권장)
이름: PSLAB_FB_APP_SECRET           값: (앱 시크릿)
```
7. 스레드 — Threads API 설정에서 권한 `threads_basic`, `threads_content_publish` 승인 후 토큰 발급:
```
이름: PSLAB_THREADS_ACCESS_TOKEN     값: (스레드 장기 토큰)
이름: PSLAB_THREADS_THREADS_USER_ID  값: (스레드 사용자 ID)
이름: PSLAB_THREADS_APP_ID           값: (Threads 앱 ID, 권장)
이름: PSLAB_THREADS_APP_SECRET       값: (Threads 앱 시크릿, 권장)
```
※ 인스타 게시물이 '일부 공개'로 보이면 API 문제가 아니라 **계정이 비공개** 상태입니다 — 앱에서 공개(프로페셔널)로 전환하세요.

## 5. 구글 블로그 — Blogger (계정 수령 후)

1. 블로그 개설: https://www.blogger.com → 새 블로그 (예: `daeguis.blogspot.com`) → 설정에서 **블로그 ID** 복사(주소창 `blogID=숫자`)
2. Google Cloud: https://console.cloud.google.com → 새 프로젝트 `daeguis-sns` → 'API 및 서비스'에서 **Blogger API v3** 사용 설정
3. 사용자 인증 정보 > OAuth 클라이언트 ID(웹 애플리케이션) 생성 — 리디렉션 URI에 추가:
```
https://developers.google.com/oauthplayground
```
4. OAuth Playground: https://developers.google.com/oauthplayground → 우상단 ⚙ > "Use your own OAuth credentials" 체크 → 클라이언트 ID/시크릿 입력 → Step1 스코프 입력:
```
https://www.googleapis.com/auth/blogger
```
   → [Authorize APIs] → 구글 로그인 → Step2 [Exchange authorization code for tokens] → **Refresh token** 복사
5. Secrets 등록 (4개):
```
이름: PSLAB_BLOGGER_CLIENT_ID       값: (OAuth 클라이언트 ID)
이름: PSLAB_BLOGGER_CLIENT_SECRET   값: (OAuth 시크릿)
이름: PSLAB_BLOGGER_REFRESH_TOKEN   값: (Refresh token)
이름: PSLAB_BLOGGER_BLOG_ID         값: (1번의 블로그 ID 숫자)
```

## 6. 유튜브 (계정 수령 후)

1. 유튜브 채널 개설 → https://www.youtube.com/account_advanced 에서 **채널 ID**(UC로 시작) 복사
2. 5번과 같은 Google Cloud 프로젝트에서 **YouTube Data API v3** 사용 설정
3. OAuth Playground(위와 동일 절차)에서 스코프만 아래로:
```
https://www.googleapis.com/auth/youtube.upload
```
   → Refresh token 발급
4. Secrets 등록 (4개):
```
이름: PSLAB_YOUTUBE_CLIENT_ID       값: (OAuth 클라이언트 ID — Blogger와 같은 값 사용 가능)
이름: PSLAB_YOUTUBE_CLIENT_SECRET   값: (OAuth 시크릿)
이름: PSLAB_YOUTUBE_REFRESH_TOKEN   값: (Refresh token)
이름: PSLAB_YOUTUBE_CHANNEL_ID      값: (UC로 시작하는 채널 ID)
```
⚠ 구글 앱이 '테스트' 상태면 refresh token이 **7일마다 만료**됩니다(만료 시 위 4단계만 재실행). 완전 무인을 원하면 OAuth 동의화면 게시(검수)를 신청하세요 — 개인정보처리방침 페이지 필요, 보통 며칠~몇 주.
⚠ 쇼츠 공개범위는 시스템 기본이 **전체 공개(public)**입니다 — 따로 건드릴 것 없음.

## 7. 링크드인 (계정 수령 후)

1. 회사 페이지 개설: https://www.linkedin.com/company/setup/new/
2. 개발자 앱 생성: https://developer.linkedin.com/ → [Create app] (회사 페이지 연결 필요)
3. Products 탭에서 추가:
```
Share on LinkedIn
Sign In with LinkedIn using OpenID Connect
```
4. Auth 탭에서 액세스 토큰 발급(OAuth 2.0 도구 사용) — 스코프:
```
w_member_social
```
5. Secrets 등록 (2개):
```
이름: PSLAB_LINKEDIN_ACCESS_TOKEN  값: (액세스 토큰)
이름: PSLAB_LINKEDIN_AUTHOR_URN    값: urn:li:organization:회사페이지숫자ID
```
   (개인 계정으로 발행하려면 `urn:li:person:본인ID`)
⚠ 링크드인 토큰은 **60일 만료 + 자동 갱신 불가** — 만료 전 대시보드 경보가 뜨면 4번만 재실행.

## 8. 네이버 블로그 (수동 발행 — 계정만 있으면 끝)

네이버는 공식 발행 API가 없어 자동발행이 불가합니다. 블로그 개설(https://blog.naver.com)만 해두면, 대시보드 네이버 블로그 탭의 **복사 도우미**(본문 복사 + 이미지 다운로드 버튼)로 주 2회 붙여넣기만 하면 됩니다. 시크릿 등록 없음.

## 9. 최종 스위치 (모든 연동 확인 후, 맨 마지막)

1. Pages 켜기: 저장소 Settings > Pages > Source를 **GitHub Actions**로 → 대시보드 주소 `https://leejiho-pslab.github.io/daeguis-sns/`
2. Variables에 실발행 스위치 (이걸 켜기 전까지는 안전 시뮬레이션):
```
이름: PSLAB_DRY_RUN
값: false
```
3. Actions 탭에서 워크플로 [Run workflow] 수동 실행 → 대시보드 체크리스트 5/5 확인 → 18:00 첫 자동발행 + 텔레그램 알림 확인.
