## 1. 카테고리 구조 — 대구탕이 속한 시장

- **대구탕 = '해장국·생선탕' 교집합 카테고리.** 소비 상황은 ①해장 ②점심 식사 ③몸보신·가족 외식 ④술안주(찜·볶음·전골) ⑤가정 조리(레시피·밀키트).
- 시장 공급 구조: 부산(해운대·광안리·송도)·거제(외포항, **전국 대구 출하량의 30%**, 거제대구축제)·진해 등 남해안 산지 노포와 서울 삼각지 '대구탕 골목' 등 **개별 노포 중심**. 체계화된 프랜차이즈는 부재했음 → **대구일색이 "최초의 대구탕 프랜차이즈" 포지션 선점**.
- 생대구 제철: **12~2월 겨울** (산란기 남해안 회유). 여름엔 냉동·목살 활용 — 대구일색의 '대구목살 전처리 공급'은 계절 수급 리스크를 낮추는 구조.

## 3. 계절성 — 콘텐츠 캘린더의 뼈대

**대구탕 월별 검색 지수 (데이터랩, 최근 2년)**

| 월 | 24-25시즌 | 25-26시즌 | 패턴 |
|---|---|---|---|
| 7월 | 13.7 | 14.3 | 저점 구간 |
| 8월 | 15.9 | 15.2 | 저점+말복·보양 수요 소폭 반등 |
| 9월 | 16.4 | 14.3 | 회복 시작 |
| 10월 | 22.2 | 18.8 | **본격 상승** |
| 11월 | 27.3 | 22.1 | 상승 |
| 12월 | 29.2 | 23.8 | 피크 |
| 1월 | 29.7 | 24.0 | **연중 최고점** (신년회·해장·제철) |
| 2월 | 21.1 | 16.3 | 급락 |
| 3~6월 | 18→14 | 14→11 | 완만한 하락 |

- **겨울 피크(12~1월)가 여름 저점(6월)의 약 2.1~2.6배.**
- '대구탕 끓이는법/레시피'는 계절성이 더 극단적: **11월 지수 100 vs 6월 15 (약 7배)** — 김장철·수능 이후 '집에서 끓이기' 수요 폭발.
- '해장국'은 연중 안정(계절 진폭 ±20% 수준) → 여름 비수기에는 해장·술국 프레임으로 수요 방어.
- 8월 온보딩 → **9~10월 채널 기반 구축 → 11~1월 검색 폭증 시즌에 콘텐츠 자산이 노출되도록 역산 설계**가 최적 (겨울 시즌 3개월 전 시작은 시기적으로 유리).

## 4. 외식·프랜차이즈 트렌드 (뉴스 종합)

1. **고물가 → 국·탕류 간편식(RMR) 성장**: "집에서도 전문점 수준의 국·탕류를 합리적 가격에" (신세계푸드 × 중앙해장 간편식 확대 보도, 2026-02). 유명 맛집 IP의 밀키트화가 검증된 공식 — 속씨원한대구탕(경쟁사)도 밀키트·전국택배로 전국구화.
2. **건강식·웰니스 외식**: 저지방·고단백, 약선 콘셉트 확장(약선흑염소 57호점 보도 등). 대구는 대표적 저지방·고단백 생선 → 대구일색의 공식 포지셔닝과 일치.
3. **K푸드·한식 프랜차이즈 수요**: 한주에이알티 자체 설문(전국 1,000명) — **84% "K푸드 확산 위해 다양한 한식 프랜차이즈 필요"**.
4. **국밥·해장국 = 소자본 창업 스테디셀러**: 창업 커뮤니티에서 "계절 안 타는 안정 매출" 아이템으로 상시 소비. 대구일색도 창업 카페에서 '국밥·해장국 창업 1순위 아이템'으로 소구되는 중.
5. **창업 검색 수요**: '소자본창업' 월평균 지수 55.6 > '프랜차이즈창업' 28.6 >> '국밥창업+해장국창업' 5.4 > '음식점창업+외식창업' 2.8. 창업 타깃 콘텐츠는 **'소자본'·'프랜차이즈' 대형 키워드 + '국밥/해장국/탕 창업' 니치 키워드** 이중 구조로.

## 5. 소비자 질문 분석 (지식iN — '궁금증 증가' 목표의 소재 뱅크)

실제 질문 유형 (검색 상위):
- 조리: "얼큰 대구탕 재료 손질 어떻게?", "맑은 대구탕 초보 팁", "육수 — 멸치 vs 코인", "비린내 제거", "두부 넣어야 하나", "어울리는 추가 재료"
- 비교: "대구탕 vs 매운탕 뭐가 맛있나" (맑고 시원 vs 진하고 칼칼 구도)
- 맛집: **"서울 대구탕 맛집 추천해주세요 — 부산 같은 맑은 대구탕을 서울에서 못 찾겠다"** ← 대구일색이 정확히 메울 수 있는 니즈 (서울 직영 3개점)
- 상황: 집밥 메뉴 추천, 겨울철 인기, 해장

→ SNS 콘텐츠 포맷 제안 근거: "대구탕 상식/레시피 카드뉴스", "맑은탕 vs 얼큰탕 취향 테스트", "서울에서 부산식 대구탕", "해장 루틴" 등 질문-응답형 콘텐츠가 검색·관심사와 직결.

## 6. 시장 기회 요약 (제안서용)

1. **프랜차이즈 백지 시장**: 대구탕 카테고리에 전국 단위 프랜차이즈 경쟁자가 사실상 없음 — 선점 스토리가 그대로 뉴스가 됨.
2. **서울의 공급 공백**: 서울 대구탕은 삼각지 골목·노포 중심, '깔끔한 브랜드형 매장'은 희소 — 지식iN에서 확인되는 미충족 수요.
3. **정보성 검색 >> 맛집 검색**: 레시피 검색량이 맛집 검색량의 3.6배 → 블로그/유튜브 정보성 콘텐츠로 상위 노출 → 브랜드 인지로 전환하는 퍼널 유효.
4. **밀키트·유통 확장 스토리**: 다이클로 협업 + 낙성대점 밀키트 실적 → 매장 없는 지역 고객까지 SNS 타깃 확장 가능.
5. **계절 역산 타이밍**: 8월 시작 → 겨울 검색 폭증(11~1월) 전에 콘텐츠·채널 자산 축적 완료.

### 한계 고지
- 데이터랩은 상대지수만 제공 — 절대 검색량·경쟁정도·클릭수는 네이버 광고주센터 키워드 도구 실측으로 보완할 것 (03 문서 조회 리스트/기입표 준비됨).
- 유튜브 콘텐츠 지형은 API 일일 쿼터 초과로 미조사 → 후속 조사 항목.
