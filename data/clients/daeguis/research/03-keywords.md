# 핵심 키워드 체계 — 네이버 키워드 도구 연동 준비

> 🖥 대시보드(항상 최신): https://claude.ai/code/artifact/55d76711-dff6-48e2-ab8b-856a3fc0526d — 이 문서의 요약은 대시보드 📊 리서치 탭에서 확인

> 조사일: 2026-07-17 · 기반: 네이버 데이터랩 상대지수 + 검색결과·리뷰 해시태그 분석
> **사용법**: 아래 "조회 배치"를 네이버 광고주센터 > 도구 > 키워드 도구에 **한 줄에 하나씩, 5개 단위**로 입력해 조회 → 결과(월간검색수 PC/모바일, 월평균클릭수, 경쟁정도, 노출광고수)를 §5 기입표에 채우면 됨. '전체 다운로드' CSV를 이 폴더(`keyword-tool-exports/`)에 저장하면 이후 자동 반영 가능.
> ⚠️ 비즈머니 잔액 부족으로 광고는 일시중지 상태여도 **키워드 도구 조회는 가능** (연관키워드 조회는 파워링크 캠페인 유형 기준).

## 1. 키워드 체계 (6개 레이어)

### L1. 브랜드 키워드 — 인지도·평판 측정 기준
`대구일색` `대구일색 서초역점` `대구일색 보라매공원점` `대구일색 낙성대점` `대구일색 메뉴` `대구일색 가격` `대구일색 창업` `대구일색 가맹` `대구일색 밀키트`

### L2. 카테고리(일반) 키워드 — 검색광고·SEO 핵심
`대구탕` `대구지리` `맑은대구탕` `얼큰대구탕` `생대구탕` `대구뽈찜` `대구뽈탕` `대구전골` `대구술국` `알곤볶음` `대구요리` `생선탕` `해장국` `해장국맛집` `술국`

### L3. 정보성 키워드 — 블로그·유튜브 콘텐츠용 (검색량 최대 레이어)
`대구탕 끓이는법` `대구탕 레시피` `맑은대구탕 끓이는법` `대구탕 재료` `대구탕 비린내 제거` `대구 손질법` `대구탕 효능` `대구 제철` `대구탕 칼로리` `해장국 추천` `해장 음식` `겨울 보양식` `여름 보양식` `몸보신 음식`

### L4. 지역+상황 키워드 — 플레이스·매장 홍보용 (지점별)
- 서초역점: `서초역 맛집` `서초 대구탕` `교대역 맛집` `서초 해장국` `법원 근처 맛집` `서초 혼밥` `서초 회식장소` `강남 대구탕`
- 보라매공원점: `보라매공원 맛집` `신대방 맛집` `신림 대구탕` `보라매 해장국` `보라매병원 맛집` `동작구 맛집`
- 낙성대점: `낙성대 맛집` `낙성대역 맛집` `인헌시장 맛집` `봉천동 맛집` `관악구 대구탕` `서울대입구 맛집`
- 공통 확장: `서울 대구탕` `서울 대구탕 맛집` `서울 해장 맛집` (+ 신규 출점 시 상권명 추가)

### L5. 창업 키워드 — 프랜차이즈 문의 목표 직결
`프랜차이즈 창업` `소자본 창업` `외식 창업` `음식점 창업` `국밥 창업` `해장국 창업` `탕 전문점 창업` `대구탕 창업` `한식 프랜차이즈` `1억 창업` `부부 창업` `퇴직 후 창업` `프랜차이즈 창업박람회`

### L6. 시즌·트리거 키워드 — 발행 캘린더 연동
| 시즌 | 키워드 |
|---|---|
| 여름(7~8월) | `여름 보양식` `이열치열` `초복 중복 말복 음식` `여름 해장` |
| 가을(9~10월) | `환절기 몸보신` `따뜻한 국물` |
| 겨울(11~1월) | `겨울 제철 음식` `대구 제철` `겨울 보양식` `연말 회식` `신년회 해장` `수능 도시락/수험생 몸보신` |
| 상시 | `해장` `혼밥` `직장인 점심` `회식장소` `밀키트 추천` |

## 2. 키워드 도구 조회 배치 (5개씩 복붙용)

```
배치 1 (브랜드):      대구일색 / 대구일색 메뉴 / 대구일색 창업 / 대구일색 밀키트 / 대구일색 서초
배치 2 (카테고리 핵심): 대구탕 / 대구지리 / 맑은대구탕 / 얼큰대구탕 / 생대구탕
배치 3 (카테고리 확장): 대구뽈찜 / 대구전골 / 대구술국 / 생선탕 / 대구요리
배치 4 (해장 축):      해장국 / 해장국맛집 / 해장음식 / 술국 / 해장
배치 5 (정보성):       대구탕끓이는법 / 대구탕레시피 / 대구탕효능 / 대구제철 / 대구탕칼로리
배치 6 (지역-서초):    서초역맛집 / 서초대구탕 / 교대역맛집 / 서초해장국 / 강남대구탕
배치 7 (지역-보라매):  보라매공원맛집 / 신대방맛집 / 신림대구탕 / 보라매병원맛집 / 동작구맛집
배치 8 (지역-낙성대):  낙성대맛집 / 낙성대역맛집 / 인헌시장맛집 / 봉천동맛집 / 서울대구탕
배치 9 (창업 대형):    프랜차이즈창업 / 소자본창업 / 외식창업 / 음식점창업 / 한식프랜차이즈
배치 10 (창업 니치):   국밥창업 / 해장국창업 / 대구탕창업 / 탕전문점창업 / 1억창업
배치 11 (시즌):        여름보양식 / 겨울보양식 / 몸보신음식 / 밀키트추천 / 겨울제철음식
배치 12 (경쟁사):      속씨원한대구탕 / 고마대구탕 / 원대구탕 / 자원대구탕 / 구옥반가
```
- 입력 시 띄어쓰기는 키워드 도구가 무시하므로 붙여쓰기 기준. '조회하기' 후 연관키워드 목록에서 **월간검색수 높은 파생 키워드를 추가 수확**할 것 (특히 '대구탕' 조회 시 연관키워드가 L2~L4를 자동 확장해 줌).
- 업종 필터 활용: 조회 기준에서 '업종 > 음식점 > 한식'을 병행 조회하면 시즌월 추천 키워드도 확보 가능.
