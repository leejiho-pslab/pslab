# 경쟁사 심층 조사 — 대구탕/유사 업종

> 조사일: 2026-07-17 · 기준: 네이버 검색량(데이터랩 상대지수 — 키워드 도구 실측치로 확정 예정), 블로그 리뷰, 언론, 맛집 플랫폼(다이닝코드·블루리본·식신)
> '유사 업종 최상위'는 ①동일 카테고리(대구탕 전문) ②인접 카테고리(생선탕·해장 노포) ③창업시장 경쟁(국밥·해장국 프랜차이즈) 3개 층위로 정의.

## 2. Tier 1 — 속씨원한대구탕 (최상위 벤치마크) 상세

| 항목 | 내용 |
|---|---|
| 본점 | 부산 해운대 미포본점 (미포·달맞이길 초입) |
| 지점 | 해운대본점(해운대점), 김해직영점, 진해점, 창원 등 부산·경남 다수 + **서울 여의도점** — 직영 위주 확장 |
| 대표 메뉴 | 대구탕 15,000원(1인 상차림, 냄비 아님 뚝배기형), 대구찜, **알말이**(맛살·대구살·날치알 계란말이 — 시그니처 사이드) |
| 스타일 | 맑은 지리 베이스 + 청양고추로 '맵고 시원한' 맛 — 담백→칼칼 조절 가능, 다대기 제공 |
| 영업 | **아침 8시 오픈** (해장 아침 수요 독점), 브레이크타임 15~16시, 선불 결제, 상시 웨이팅 |
| 커머스 | **밀키트**(매장 조리 방식 그대로 급냉) — 네이버 스마트스토어(mipodaegutang), 쿠팡, 배민, **전국 택배** |
| 미디어/공신력 | 블루리본서베이 등재, 방송 다수(노는언니 등), "연예인 단골 해장 성지" 콘텐츠 다수 |
| 리뷰 톤 | "해장 끝판왕", "아침 대구탕", 가격 불만 일부(가성비 3.7점) |

**성공 공식 → 대구일색 적용 포인트**
1. '해장'이라는 상황 소유 (아침 영업 + 관광객 숙취 동선) → 대구일색은 '직장인 점심 해장 + 대구술국'으로 서울 오피스 상권 버전 구축
2. 시그니처 사이드(알말이) 콘텐츠화 → 대구일색의 '알곤볶음·뽈튀김·산더미 돌판뽈찜'을 비주얼 시그니처로 밀기
3. 밀키트·전국택배로 비매장 지역 고객 확보 → 대구일색 밀키트+다이클로 유통 스토리 강화
4. 방송·유명인 서사 축적 → 생방송투데이 출연 이력을 채널에 고정 콘텐츠로 리사이클

**약점(대구일색의 공격 각도)**: 가맹 모델 아님(직영) → 창업 시장에서는 무경쟁. 서울 커버리지 약함(여의도 1곳). 브랜드형 인테리어·표준화 아님.

## 3. Tier 2 — 지역 강자·노포 (콘텐츠 경쟁자이자 시장 검증 사례)

| 상호 | 지역 | 특징 | 시사점 |
|---|---|---|---|
| **원대구탕 본점** | 서울 용산 삼각지 | 삼각지 '대구탕 골목'의 원조격. 블루리본, **서울미래유산(2019)**, 대통령 방문 서사, 낮술 성지 | 서울 대구탕의 상징 — '골목 노포 vs 깔끔한 브랜드 매장' 구도로 차별화 가능 |
| 자원대구탕 | 서울 삼각지 | 골목 내 경쟁 노포, 겨울철 검색 상승 | 동일 |
| 고마대구탕 | 부산 광안리 | 관광+로컬 노포, 맑은탕 스타일 | 지식iN에 "고마대구탕 같은 맑은탕 서울 어디?" 질문 존재 → 대구일색 답변 포지션 |
| 구옥반가 | 부산 기장 정관 | 대구뽈찜·산더미 비주얼로 방송·리뷰 다수 | 뽈찜 비주얼 콘텐츠 벤치마크 |
| 양지바위횟집 | 거제 외포항 | 산지(전국 출하량 30%) 제철 대구탕, 거제대구축제 연계 | '산지 스토리' 콘텐츠 소재 (원물 신뢰) |
| 참식당 (1989) | 서울 마포 | 생대구 노포 | 서울 시장 레퍼런스 |
| 서울큰입탕 | 서울 마포 | 대구탕·전골·뽈찜 전문 | 서울 직접 경쟁 |
| 남도대구탕 | 서울 구로 | 생대구전골 | 서울 직접 경쟁 |
| 엄마손대구탕 / 속시원해대구탕 | 부산 송정/송도 | 로컬 맛집 | — |

**구조적 발견**: 서울의 대구탕 공급은 노포 단일 매장 중심이고 다점포 브랜드가 없음. "부산식 맑은 대구탕을 서울에서, 깔끔한 매장으로" — 대구일색만 가능한 메시지.

## 4. Tier 3 — 창업시장 경쟁 (프랜차이즈 문의 목표의 실제 경쟁자)

예비 창업자의 대안 비교군 = 국밥·해장국·탕류 프랜차이즈:

| 브랜드 | 카테고리 | 창업 소구 |
|---|---|---|
| 일품양평해장국 | 해장국·국밥 | "국밥 체인점 브랜드 1위" 자칭, 24시간 상담, 공격적 창업 마케팅(블로그 물량) |
| 부산아지매국밥 | 돼지국밥 | "사계절 안정 매출" 소구 |
| 뼈큰감자탕 | 감자탕·국밥 | 가맹비·교육비 면제 프로모션형 |
| 고향옥얼큰순대국 | 순대국 | 한식 프랜차이즈 창업비용 비교 콘텐츠에 상시 등장 |
| (참고) 꽃마름 샤브샤브 | 샤브샤브 | 자사 자매 브랜드 — 50여 가맹, 연 72% 성장, 2년 내 100호점 목표 → 본사 신뢰 스토리로 활용 |

**창업 콘텐츠에서 대구일색의 차별 포인트** (창업 카페 매물글에서 이미 통용되는 논리):
- 국밥·해장국 카테고리의 안정성 + **아직 아무도 선점 않은 '대구탕' 아이템** (골목상권 중복 출점 리스크 낮음)
- 전처리 원물 공급 → 5분 서빙, 조리 난이도·인력 부담 최소화
- 1호점 월매출 1억 실증 + 상장사 계열 본사 + 꽃마름 15년 운영 트랙레코드
- 경쟁 프랜차이즈 대비 유의점: 신생(가맹점 수 미미) — "초기 가맹 프리미엄(좋은 상권 선점)" 프레임으로 전환

## 5. 경쟁사 SNS·마케팅 활동 비교 (2026-07 검색 기준)

| 브랜드 | 네이버 블로그 리뷰 | 밀키트/커머스 | 방송 | 공식 SNS |
|---|---|---|---|---|
| 속씨원한대구탕 | 총 8,600건+ (자연 발생 다수) | 스마트스토어+쿠팡+택배 | 다수 | 스토어 중심 (계정 영향력은 미상) |
| 대구일색 | 총 16,400건 검색되나 상당수 체험단성 — 최근 낙성대점 집중 | 매장 밀키트 (온라인몰 미확인) | 생방송투데이 1회 | **미확인(부재 추정)** |
| 원대구탕 등 노포 | 자연 발생 리뷰 | 없음 | 간헐 | 없음 |

→ **격차의 본질은 '자산화'**: 속씨원한대구탕은 리뷰→커머스→전국 고객으로 이어지는 퍼널이 있고, 대구일색은 리뷰가 흩어져 브랜드 채널에 축적되지 않음. SNS 자동화(6채널 상시 발행 + 대시보드)가 이 공백을 정확히 채움 — 제안서 핵심 논리.

## 6. 키워드 도구 확정 절차

03 문서 배치 12(경쟁사 브랜드 키워드)를 키워드 도구로 조회해 **월간검색수 절대값 기준 최상위 업체를 최종 확정**하고, 본 문서 §1 표를 실측치로 갱신할 것. (현재 순위는 데이터랩 상대지수 기반 — 방향성은 신뢰 가능하나 절대량 아님)
