# 대구일색 인스타 감도 규칙서 (ig-design-spec)

> 🖥 대시보드(항상 최신): https://claude.ai/code/artifact/55d76711-dff6-48e2-ab8b-856a3fc0526d
> 근거: 사전조사 05 문서 §0-3 디자인 시스템 + 스킬 ADR-0003(이미지-전면형)·ADR-0004(가짜 글자 함정)

| 변형 | 용도 | 배경 | 글자 | 강조(1색만) |
|---|---|---|---|---|
| A 설백·에디토리얼 | 여름 기본·비교·정보 | #F7F4EE | #0E2A3C | #E8503A (웜 레드) |
| B 담청·미나리 | 맑은탕·시원함·정보성 | #EDF3F0 | #0E2A3C | #3F8A66 (미나리 그린) |

- 강조색은 **슬라이드당 1개만**. 겨울(11~1월) 에디션 전환 시 `design-variants.json`만 교체(네이비 심화).
- 저채도 회색조·클립아트·스톡사진 느낌 금지 (§0-3 회피 목록).

## 2. 타이포·레이아웃

- 헤드라인 **Pretendard ExtraBold 좌측 정렬**, 숫자·핵심어만 강조색. (이미지-전면형 전환 시
  ADR-0003의 명조 세리프 디스플레이 도입 검토 — 나눔명조 woff2 번들.)
- **커버 후킹 공식**: 굵은 핵심어 6~10자 + 큐리오시티 갭(질문·미완성 문장). 첫 장표는 반드시
  고객 인터랙션 주제(운영자 지침 ⑤ — 투표·태그·질문).
- **슬라이드당 12단어 이내**(본문 2줄), 넓은 여백. 캐러셀 구성: 표지(훅) → 본문 3~4장(라벨 01·02) → 엔딩(CTA·지점).
- 세이프존: 4:5(1080×1350) 기준 그리드 1:1 크롭을 고려해 핵심 텍스트는 중앙 밴드.

## 3. 이미지 사용 (운영자 지침 ③ + ADR-0003)

- **1순위: 공식 사이트(daeguis.co.kr) 실사진** — 자유 사용 승인됨. 시그니처 샷 3종 우선:
  ①뚝배기 김 리프트업 ②산더미 돌판뽈찜 부감 ③맑은탕 vs 얼큰탕 비교. 웜톤 클로즈업.
- 사진 확보 시 **이미지-전면형(cinema/photoA/photoB 3스타일)** 으로 전환하고, plan 항목에
  `slidePhotos`+`igStyle`을 지정한다. 사진 없는 동안은 현행 브랜드 카드(음식 라인아트 모티프:
  뚝배기·물결·고추·산더미·대구·미나리)로 발행.
- 개발환경은 외부 이미지 403 — 사진 다운로드·합성은 **CI에서만**(URL을 `bg-sources.json`류에 저장).

## 4. 가짜 글자 함정 (ADR-0004 — 대구일색 버전)

AI 생성 이미지를 쓸 경우(배경 씬 등) 확산모델이 **간판·메뉴판·앞치마 로고·소주병 라벨**이
정면으로 보이면 가짜 한글/영문을 새긴다. 회피 규칙:
- 피사체는 **텍스트-세이프 구도**로: 국물·김 매크로, 뚝배기 탑다운, 건더기 클로즈업, 손+젓가락,
  무지 그릇·트레이. 간판/메뉴판/병 라벨 정면 금지.
- 한글 텍스트는 **무조건 HTML 오버레이**(ADR-0001) — 이미지에 글자 생성 금지.
- 생성 후 **확대 비전 검수**: 글자 흔적 있는 컷은 폐기(재사용 금지). 검수 기록은 plan `captionNote`에.

## 5. 검수 체크리스트 (발행 전)

- [ ] 강조색 1개만 사용했는가 / 팔레트 외 색 없음
- [ ] 커버: 핵심어 6~10자 훅 + 인터랙션 유도 문장
- [ ] 슬라이드당 12단어 이내, 세이프존 준수
- [ ] 이미지에 가짜 글자·왜곡 없음 (확대 검수)
- [ ] 금지 소재 없음: 지역 '대구' 연상, 모기업·주가, 효능 단정, 확정수익
- [ ] 소비자 검증 어휘 사용(시원·맑음·개운·포슬포슬) + 목표(판매/인지/인터랙션) 명시
