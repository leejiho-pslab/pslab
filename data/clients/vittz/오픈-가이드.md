## 채널별 발급 목록

### 1) 인스타그램 + 스레드 (@vittz_official)
- 준비물: 인스타그램이 **비즈니스/크리에이터 계정**이고 **페이스북 페이지에 연결**되어 있어야 함
- 발급: Meta 개발자 앱 생성 → Instagram Graph API 연결 → **장기 액세스 토큰**
- 넣을 시크릿: `PSLAB_INSTAGRAM_ACCESS_TOKEN`, `PSLAB_INSTAGRAM_IG_USER_ID`,
  `PSLAB_THREADS_ACCESS_TOKEN`, `PSLAB_THREADS_THREADS_USER_ID`
- 참고: 게시물 공개 여부는 계정 설정을 따릅니다 — 앱에서 계정이 **공개**인지 확인

### 2) 유튜브 (채널 UCqfOTULeIeIurfRY-DXEoyw)
- 발급: Google Cloud 프로젝트 → **YouTube Data API v3** 활성화 → OAuth 클라이언트 생성 →
  OAuth Playground에서 `youtube.upload` 스코프로 **refresh token** 발급
- 넣을 시크릿: `PSLAB_YOUTUBE_CLIENT_ID`, `PSLAB_YOUTUBE_CLIENT_SECRET`,
  `PSLAB_YOUTUBE_REFRESH_TOKEN`, `PSLAB_YOUTUBE_CHANNEL_ID`
- ⚠️ 구글 앱을 검수(인증)받기 전에는 토큰이 **7일마다 만료**됩니다 — 완전 무인을 원하면
  앱 검수를 신청하세요(개인정보처리방침 페이지 필요, 며칠~몇 주 소요)
- 업로드 공개범위 기본값은 **전체 공개(public)** 입니다

### 3) 네이버 블로그 (vittzlighting)
- 발급할 것 없음 — 공식 발행 API가 없어 **수동(복붙) 채널**입니다
- 발행일에 대시보드 네이버 블로그 탭에 **본문 복사 + 이미지 다운로드** 버튼이 뜹니다 (약 5분 소요)

### 4) 구글 블로그 (선택)
- 새 Blogger 블로그 개설 → Google Cloud에서 Blogger API 활성화 → OAuth Playground로 refresh token
- 넣을 시크릿: `PSLAB_BLOGGER_CLIENT_ID`, `PSLAB_BLOGGER_CLIENT_SECRET`,
  `PSLAB_BLOGGER_REFRESH_TOKEN`, `PSLAB_BLOGGER_BLOG_ID`

### 5) 링크드인 (선택 — B2B/채용 브랜딩)
- LinkedIn 개발자 앱 → "Share on LinkedIn" 제품 추가 → OAuth 토큰 발급
- 넣을 시크릿: `PSLAB_LINKEDIN_ACCESS_TOKEN`, `PSLAB_LINKEDIN_AUTHOR_URN`
- ⚠️ 토큰이 약 60일마다 만료 — 만료 전 재발급 필요 (대시보드가 조기 경보)

### 6) 텔레그램 알림 (권장)
- @BotFather에서 봇 생성 → 봇을 알림방에 초대
- 넣을 시크릿: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`
- 발행 성공/실패, 토큰 만료 경보가 실시간으로 옵니다

### 7) AI 글 생성 (권장)
- Anthropic 콘솔에서 API 키 발급 → 시크릿 `ANTHROPIC_API_KEY`
- 비용 절감: Variables에 `PSLAB_CLAUDE_MODEL=claude-haiku-4-5` (월 1~2천원 수준)
- 키가 없어도 규칙기반으로 안전 동작합니다

## 마지막 스위치

모든 토큰 등록 후:
1. Variables에서 `PSLAB_DRY_RUN=false` (실발행 ON — 이전까지는 안전 시뮬레이션)
2. 워크플로 수동 실행 → 대시보드 체크리스트 완료 확인 → 첫 자동발행·텔레그램 알림 확인

## 운영 중 의견 전달

- 각 채널 탭 상단 **수정요청 게시판**: 콘텐츠 수정 요청 작성 → 처리 상태가 자동 표시
