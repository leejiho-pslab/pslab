# 02. 시장·트렌드 분석 — 조명/인테리어

> 데이터: 네이버 데이터랩 검색어 트렌드 + 쇼핑인사이트 (2025-07 ~ 2026-06, 월 단위, 상대지수)
> 상대지수는 기간 내 최대치를 100으로 하는 비율값. 절대 검색량은 광고주센터 키워드 도구로 확인(03 문서).

## 1. 카테고리 검색 계절성 (연간 리듬)

### 조명 일반 (조명·거실등·방등·LED조명)
- **가을(9~10월)이 최대 성수기**, 1월에 두 번째 피크(신년 이사·새단장), 5~6월이 연중 저점.
- `조명교체/전등교체`는 계절성이 가장 극단적: 10월 100 ← 7월 43.6 (약 2.3배). 이사철+일조량 감소 영향.
- 시사점: **8월 자동화 시작 → 9~10월 성수기 직전 램프업**으로 타이밍이 이상적.

| 키워드 | 피크 | 저점 | 패턴 |
|---|---|---|---|
| 조명 | 8월(100) → 가을 유지 | 6월(71) | 완만, 연중 수요 존재 |
| 거실등 | 9~10월(38) | 6월(21) | 가을 집중 |
| 방등 | 10월(18.3) | 6월(8.3) | 가을 집중 |
| LED조명 | 7~10월(43~47) | 6월(17.9) | 하반기 강세 |
| 조명교체·전등교체 | 9~10월(85~100) | 6월(25) | **초강력 가을 계절성** |
| 간접조명 | 7월·1월(94~99) | 6월(62) | 연중 높은 관심, 겨울 무드 수요 |
| 무드등 | 11~12월(26~28) | 6월(15) | 연말·겨울 감성 수요 |
| 식탁등 | 1월(19.5) 연중 고른 편 | 6월(13.7) | 저계절성 — 상시 소재 |
| 실링팬 | **7월(100), 5월(80)** | 2월(33) | **여름 역계절성 — 여름 매출 방어 카드** |
| 셀프인테리어 | 1월(80)·3월(79) | 6월(60) | 신년·봄 |
| 집꾸미기 | 8~9월(91~92) | 6월(50) | 늦여름~가을 |

### 운영 캘린더 함의
- **8월**: 실링팬 막바지 + 가을 새단장 예고(집꾸미기 상승 시작) → 론칭 콘텐츠 적기
- **9~11월**: 조명교체·거실등·방등 성수기 → 공간별 교체 가이드/시공 사례 집중
- **12~1월**: 무드등·간접조명·셀프인테리어 → 감성/연출 콘텐츠
- **2~4월**: 신학기 학습등·봄 리프레시 → 스탠드/부분 교체
- **5~7월**: 실링팬·천장 선풍기 시즌 → 결합형(실링팬 방등) 주력

## 2. 구매층 (쇼핑인사이트 · 인테리어조명 카테고리)

- **연령**: 40대 > 30대 > 50대 > 60대 > 20대. 30·40대가 압도적 핵심(합산 최대), 50대가 꾸준히 3위.
  20대는 비중 낮고 하락세 → 자사몰 구매층은 '집을 소유/관리하는 30~50대'.
- **성별**: 남녀 균형에 가까움(시기별로 여성 우세 ↔ 남성 우세 교차). 조명은 '여성 감성 + 남성 시공'
  양쪽 모두에게 팔리는 카테고리 → 콘텐츠도 스타일링(감성)과 설치/스펙(실용) 투트랙이 유효.

## 3. 경쟁 구도 (브랜드 검색량 상대 비교, 12개월)

| 브랜드 | 상대지수 범위 | 특징 |
|---|---|---|
| **비츠조명** | 60~72 | **연중 가장 안정적으로 높음.** 편차 작음 = 고정 팬층/재방문 수요 |
| 공간조명 | 37~100 | 8월 프로모션성 스파이크 후 하락. 평시엔 비츠보다 낮음 |
| 루이스폴센(수입 프리미엄) | 22~33 | 감성/럭셔리 수요 꾸준 — 프리미엄 관심층 존재 증명 |
| 라이마스 | 3~5 | 소규모 |
| 마르조명 | ~0 | 미미 |

- 비츠는 **국내 온라인 조명몰 중 브랜드 검색 수요 1~2위권**. 자동화의 역할은 신규 인지 확보보다
  ①검색 수요를 콘텐츠로 받아내기(블로그 SEO) ②기존 인지 고객의 재구매/확장 카테고리 교차판매.
- 간접 경쟁: 오늘의집(플랫폼), 이케아(가구+조명), 쿠팡/스마트스토어 저가 조명. 차별화 축은
  **설치 서비스 + 국산/정품 LED 신뢰 + 공간 스타일링 제안력**.

## 4. 고객 언어 (카페·지식iN 관찰)

실제 소비자가 쓰는 표현 — 콘텐츠 제목/본문에 그대로 쓸 것:

- **구매 탐색**: "거실등 추천", "엣지등처럼 얇은 등", "눈 안 아픈 조명(눈뽕)", "몽돌조명", "바리솔 대안"
- **시공 불안**: "셀프로 가능할까요", "구리선 연결", "안정기/모듈 차이", "천장 구멍 걱정", "브라켓"
- **품질 언어**: "플리커프리", "국산", "KC인증", "삼색변환", "주광색/주백색/전구색", "잔광현상"
- **AS 우려**: "2년도 안 됐는데 고장", "단종이라 AS 불가" → 보증·수리 정책을 선제적으로 알리는 콘텐츠 기회
- **상황 키워드**: 이사, 신혼집, 아이방, 학습등(초등 책상 스탠드), 옥탑/오래된 집 교체

## 5. 콘텐츠 성과 신호 (자사 유튜브에서 확인된 것)

- 일반 1분 30초 영상: 조회 1~2천 수준.
- **"방등 조명 셀프 설치하기" 23초 쇼츠: 92,000회** — 짧은 실용 하우투가 압도적으로 터짐.
- 연예인 집 인테리어 소재: 평균 이상(1.3~1.7천)이나 폭발력은 하우투만 못함.
- 함의: 쇼츠는 **"30초 안에 끝나는 셀프 설치/문제 해결"** 포맷을 주력으로.

## 6. 요약 (제안서용 한 단락)

조명 검색 수요는 9~10월 이사·새단장 시즌에 최대 2.3배까지 증폭되는 강한 계절성을 가지며,
8월 자동화 가동은 이 성수기를 정조준하는 타이밍이다. 구매층은 30~50대 남녀 균형형이므로
감성 스타일링과 실용 시공 정보의 투트랙 콘텐츠가 필요하다. 비츠는 이미 브랜드 검색량에서
경쟁 조명몰을 안정적으로 앞서는 만큼, SNS 자동화의 KPI는 신규 인지보다 '검색 수요의 콘텐츠
선점(블로그 SEO)'과 '실링팬·커튼·타일 등 확장 카테고리 교차 노출'에 두는 것이 합리적이다.
자사 유튜브에서 이미 검증된 '초단편 셀프 설치 쇼츠'(9.2만 조회)가 볼륨 성장의 열쇠다.
