# 09. 운영자 콘텐츠 지침 (상시 적용 · 2026-07-17 지시)

> 운영자가 직접 내린 **모든 콘텐츠에 상시 적용되는 5대 지침**. 원문 그대로 보존하고,
> 시스템 반영 위치와 실행 해석을 함께 기록한다. 이 지침은 `brand-brief.json`(감도)과
> `channel-guides.json`(채널 가이드)에 주입되어 **AI 글 생성 프롬프트에 항상 포함**된다.

## 지침 원문

1. **최상위의 디자인 감도 및 톤앤무드를 유지한다**
2. **제품 개별을 디테일하게 얘기한다 / 카테고리로 얘기한다 / 시의성으로 큐레이션해서 얘기한다 / 테마와 컨셉으로 큐레이션해서 얘기한다**
3. **사이트의 모든 이미지를 자유롭게 사용한다**
4. **내용의 핵심은 항상 목표를 위해야 한다 = 목표 = 제품 판매 / 브랜드 인지도 증가 / 고객 인터랙션**
5. **첫 장표는 세부 고객들의 인터랙션이 될 수 있는 주제로 진행한다**

## 실행 해석

| # | 실행 기준 |
|---|---|
| 1 | 웜 미니멀·전구빛 무드의 전용 카드 변형(W 웜 라이트 / V 전구빛 다크)으로 렌더. 과채도·클립아트·잡다한 요소 금지. 기존 피드와 톤 연속성 |
| 2 | 콘텐츠마다 화법 1개를 명시하고 로테이션: **제품 디테일**(스펙·가격·차별점 깊이) / **카테고리**(거실등·방등 등 구매 단위) / **시의성**(계절·검색 트렌드 연동 — 02 문서 계절성) / **테마·컨셉**(미드센추리, 카페 같은 집 등) |
| 3 | vittz.co.kr·공식 스토어의 제품컷/시공컷을 콘텐츠에 자유 활용. 개발 환경은 외부 이미지 접근이 막혀 있으므로 **이미지 URL을 시드 파일(blog-figures.json 등)에 저장 → CI에서 다운로드** 방식으로 반영 |
| 4 | 모든 콘텐츠는 발행 전 "이 콘텐츠의 목표는 판매/인지/인터랙션 중 무엇인가"를 kicker 또는 rationale에 명시. 목표 없는 정보 나열 금지. CTA는 목표와 일치시킬 것 |
| 5 | 캐러셀 1장차·블로그 도입부는 타깃 고객이 답하고 싶어지는 **질문·투표·공감 상황**으로 시작 (예: "실링팬 vs 서큘레이터, 우리 집 정답은?") |

## 시스템 반영 위치

- `data/clients/vittz/brand-brief.json` → `sensibility` 필드 [운영자 상시 지침] 블록 — 모든 채널 프롬프트에 주입
- `data/clients/vittz/channel-guides.json` → 각 채널 `guide` 앞부분 — 채널별 프롬프트에 주입
- 카드 렌더: `scripts/render-cards.mjs`의 웜 변형 `W`/`V` (지침 1)
- 테스트 포스팅 4건(인스타 2·블로그 2)이 이 지침의 첫 적용 사례 — `plan.json` 참조
