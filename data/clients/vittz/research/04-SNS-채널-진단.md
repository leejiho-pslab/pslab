## 2. 채널별 상세 진단

### 인스타그램 (@vittz_official)
- 팔로워 3.2만은 국내 조명몰 계정 중 상위권. 게시물 3,559개 = 오랜 기간 축적된 피드.
- 기회: 캐러셀(스타일링 팁·비포애프터) 자동발행으로 **일 1회 일관 노출** 체계화.
- 자동화 적합성: ✅ Instagram Graph API 캐러셀 자동발행 가능 (계정 공개/전문가 계정 전제).

### 네이버 블로그 (vittzlighting)
- 콘텐츠 유형: ①특가/기획전 ②셀프 설치 가이드 ③제품 소개 ④언론 보도 아카이브(회사 연혁 자료 풍부).
- 이웃 6.5천, 브랜드 검색 시 공식 블로그가 상위 노출 — SEO 기반 이미 탄탄.
- 자동화 적합성: ⚠️ 공식 발행 API 없음 → 대시보드에서 **본문 복사+이미지 다운로드 후 수동 게시**
  (시스템이 원고·이미지까지 전부 준비, 담당자는 5분 복붙).

### 유튜브 (비츠)
- 누적 조회 1,870만·영상 1,043개의 대형 아카이브. 구독자(9.8천) 대비 조회수가 큰 구조 =
  **검색/추천 유입형 채널** (구독 기반이 아니라 하우투 검색으로 소비됨).
- 최근 포맷: 1분 24~31초 세로형 정보 영상 주 2~3회 (욕실 트렌드, 잔광 해결, 커튼 실측, 타일 시공…).
  평균 조회 1~2천. **23초 쇼츠 "방등 셀프 설치"는 9.2만 회** — 초단편 하우투의 잠재력 입증.
- 자동화 적합성: ✅ YouTube Data API 자동 업로드 가능(쇼츠). 기존 채널 흐름을 해치지 않게
  '모션 배경 + 자막 오버레이 + BGM' 쇼츠를 보완재로 투입.

### 부재/보류 채널
- **스레드**: 미확인(개설 여부 확인 필요). 인스타 계정 연동으로 저비용 개설 가능 → 신규 권장.
- **구글 블로그·링크드인**: 미보유로 보임. 구글 검색 유입(구글 블로그)과 B2B/채용 브랜딩(링크드인)은
  선택 옵션으로 제안.

## 3. 진단 결론 (제안서용)

1. 비츠는 이미 **3.2만 인스타 + 1,870만 누적 조회 유튜브 + 검색 상위 블로그**라는 강한 채널 자산을
   보유했으나, 발행 리듬과 포맷이 채널별로 분절되어 있다. 자동화의 가치는 "0→1"이 아니라
   **"매일 같은 시각, 같은 품질, 채널 맞춤 포맷으로"의 일관성**을 만드는 데 있다.
2. 유튜브에서 검증된 승리 공식(초단편 셀프 설치 하우투)을 쇼츠 자동 파이프라인의 기본 포맷으로 삼는다.
3. 네이버 블로그는 API 부재로 유일한 수동 채널이지만, 조명 카테고리의 검색 수요(02 문서 계절성)를
   고려하면 **가장 ROI가 높은 채널** — 자동화가 원고·대표이미지·본문 이미지를 전부 만들어주고
   담당자는 복붙만 하는 운영으로 부담을 최소화한다.
4. 성과 수집(인사이트) → learning.json → 다음 기획 반영의 선순환은 인스타·유튜브·스레드에서 자동,
   블로그는 주간 리포트에서 수동 지표 입력(선택)으로 보완한다.
