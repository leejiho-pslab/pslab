- `../brand-brief.json`에 이 조사의 요약본(분석/방향성/감도)을 시드해 둠 —
  자동화 가동 시 Claude 생성 프롬프트에 "[운영자 브랜드 노트]"로 주입되는 파일.
- 네이버 키워드 도구는 API가 없어 **광고주센터에서 담당자가 직접 조회** 필요.
  03 문서의 배치표(한 번에 5개)를 순서대로 입력하고 결과(월간검색수 PC/모바일, 경쟁정도)를
  같은 문서의 기록표에 채워 넣으면 키워드 전략이 완성된다.
