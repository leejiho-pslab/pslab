# 03. 키워드 전략 — 네이버 광고주센터 키워드 도구 활용

> 네이버 키워드 도구(광고주센터 → 도구 → 키워드 도구)는 API가 없어 **담당자가 직접 조회**한다.
> 키워드 입력창은 **한 줄에 하나씩, 최대 5개**까지 → 아래 배치를 순서대로 입력하고
> "조회하기" → 연관키워드 결과에서 월간검색수(PC/모바일)·월평균클릭수·경쟁정도를 확인,
> "전체 다운로드"로 엑셀 저장 후 본 문서 6장 기록표에 옮겨 적는다.
> ※ 조회 전 비즈머니 잔액 경고(광고 일시중지)는 키워드 조회 자체와는 무관하나,
> 파워링크 캠페인이 있어야 연관키워드 조회·추가가 지원된다는 안내 문구 참고.

## 1. 키워드 체계 (4계층)

| 계층 | 역할 | 예 |
|---|---|---|
| 브랜드 | 지명 수요 방어·전환 | 비츠조명, 비츠 조명 |
| 카테고리(대) | 볼륨 확보·인지 | 조명, LED조명, 인테리어조명 |
| 공간/제품(중) | 구매 직결 — **주력** | 거실등, 방등, 주방등, 식탁등, 실링팬 |
| 정보성/롱테일(소) | 블로그 SEO·쇼츠 소재 | 방등 셀프교체, 잔광현상, 플리커프리 |

## 2. 키워드 도구 입력 배치 (한 번에 5개씩, 총 8배치)

**배치 1 — 브랜드·지명**
```
비츠조명
비츠 조명
조명쇼핑몰
조명 전문점
인테리어조명
```

**배치 2 — 공간별 메인등 (구매 전환 핵심)**
```
거실등
방등
주방등
식탁등
현관 센서등
```

**배치 3 — 제품 유형 (디자인/감성)**
```
펜던트조명
무드등
간접조명
벽등
레일조명
```

**배치 4 — 시즌 주력 (여름~초가을)**
```
실링팬
천장 선풍기
실링팬 방등
LED 실링팬
우드 실링팬
```

**배치 5 — 교체·시공 (가을 성수기 대비)**
```
조명교체
전등교체
LED방등 교체
조명 설치
거실등 교체
```

**배치 6 — 스펙·신뢰 (검색 상세형)**
```
LED방등
플리커프리 조명
삼색변환 LED
LED 매입등
LED 평판등
```

**배치 7 — 확장 카테고리 (토탈 인테리어)**
```
암막커튼
욕실등
욕실 리모델링
타일 시공
호텔침구
```

**배치 8 — 상황·타깃 (롱테일)**
```
신혼집 조명
아이방 조명
책상 스탠드
학습용 스탠드
미드센추리 조명
```

## 3. 결과 해석 기준 (키워드 도구 지표 읽는 법)

- **월간검색수(모바일 위주로 볼 것)**: 조명류는 모바일 비중이 높음. PC+모바일 합산으로 볼륨 판단.
- **경쟁정도 '높음' + 검색수 많음** = 파워링크 단가 비쌈 → 광고보다는 **콘텐츠(블로그/쇼츠)로 선점**.
- **경쟁정도 '낮음~중간' + 검색수 1천~1만** = 블로그 SEO 스위트스팟 → 우선 공략.
- **연관키워드 열**에서 예상 밖의 롱테일(예: "방등 60W", "거실등 LED 교체 비용")을 수집해
  콘텐츠 제목 풀에 추가 — 자동화 시스템의 채널 가이드 `주제:` 줄에 넣으면 소재 풀로 반영됨.
- 조회 결과는 **월간 예상 실적 보기**로 시즌별 변화도 확인 (02 문서의 계절성과 교차 검증).

## 4. 채널별 키워드 매핑 (자동화 콘텐츠 배분)

| 채널 | 키워드 계층 | 활용 방식 |
|---|---|---|
| 네이버 블로그 | 정보성·교체·시공 + 공간별 | 제목에 키워드 전진 배치, 검색 유입(SEO) 본진 |
| 인스타그램 | 제품 유형·감성 (펜던트, 무드등, 미드센추리) | 해시태그 + 캐러셀 스타일링 |
| 유튜브 쇼츠 | 시공·문제해결 (셀프교체, 잔광, 센서등) | 30초 하우투, 제목에 검색어 그대로 |
| 스레드 | 상황·타깃 (신혼집, 아이방) + 꿀팁 요약 | 대화형 짧은 팁 |
| 링크드인/구글 블로그 | 브랜드·시장 (인테리어 트렌드, 플랫폼 성장) | 브랜드 스토리·전문성 |
