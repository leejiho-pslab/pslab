# 08. SNS 채널별 운영 전략 — 벤치마크 기반 상세 설계

> 작성일 2026-07-17 · 근거: 01~07 조사 + 벤치마크 채널 운영 방식 추가 조사
> (오늘의집 공식 콘텐츠 마케팅 사례, IKEA 소셜 전략 케이스스터디, Govee 바이럴 성장 사례,
> Home Depot 하우투 미디어 전략 등). 각 채널의 **디자인·기획·내용 구성**을 분해하고
> 비츠에 맞는 운영 설계로 번역했다. 콘텐츠 제작 전 단계의 전략 문서이며,
> 여기 정의된 포맷·규격이 이후 자동화(카드 렌더·쇼츠 빌드·AI 원고)의 스펙이 된다.

## 0. 전체 프레임 — 채널 포트폴리오 설계

### 0-1. 퍼널 상의 채널 역할

```
[발견]      유튜브 쇼츠 ─ 검색·추천으로 신규 유입 (하우투 수요)
[발견]      인스타그램 릴스/캐러셀 ─ 공간 영감 탐색층 포착
[탐색]      네이버 블로그 ─ 구매 직전 검색 수요 흡수 (SEO 본진)
[탐색]      구글 블로그 ─ 구글 검색 보조 흡수
[관계]      스레드 ─ 저비용 대화·실험 채널
[신뢰]      링크드인 ─ B2B(시공사·자영업자)·채용·기업 브랜딩
[전환]      자사몰(vittz.co.kr) + 스마트스토어 ─ 모든 채널의 종착지
```

- 벤치마크 근거: 오늘의집은 채널마다 **타깃과 콘텐츠를 다르게 편성**(인스타=25-34 여성 영감,
  카카오 1boon=40대 살림 노하우)했고, 이것이 채널 성장의 핵심이었다. 비츠도 "같은 소재,
  채널별 다른 가공"을 원칙으로 한다 — 자동화 시스템의 채널 라운드로빈과 정확히 일치하는 문법.
- IKEA는 "무드 팔레트·아늑한 조명·여백"으로 **오프라인 매장 경험을 피드 비주얼로 복제**한다.
  비츠의 오프라인 매장·쇼룸·시공 현장이 같은 역할의 원천 자산이다.

### 0-2. 콘텐츠 리사이클링 구조 (1소재 → 6채널)

```
원천 소재 1건 (예: "가을 이사철, 거실등 교체")
 ├─ 네이버 블로그: 1,500자 SEO 원고 + 본문 이미지 4~6장 (심화)
 ├─ 구글 블로그: 같은 원고 재구성 (중복 아닌 리라이트)
 ├─ 인스타그램: 캐러셀 6장 (핵심만 시각 요약)
 ├─ 스레드: 3줄 핵심 팁 + 이미지 1장 (대화형)
 ├─ 유튜브 쇼츠: 30초 하우투 (교체 과정)
 └─ 링크드인: 시장 데이터 관점 리라이트 (이사철 조명 수요 2.3배)
```

### 0-3. 공통 디자인 시스템 (모든 채널 카드·커버·오버레이의 기준)

| 요소 | 규격 | 근거 |
|---|---|---|
| 팔레트 | 웜화이트 #FAF7F2 / 딥차콜 #26221D / 앰버 #E8A13D / 전구빛 그라데이션 보조 | IKEA식 "무드 팔레트" — 조명 브랜드는 '빛의 온도'가 곧 브랜드 컬러 |
| 타이포 | Pretendard. 카드 헤드라인 굵게 2줄 이내, 본문 최대 3줄 | 모바일 3초 가독 |
| 사진 톤 | 저녁 시간대 전구빛 무드, 과채도 금지, 생활감 있는 실제 공간 | 오늘의집 UGC가 증명한 '진짜 집' 신뢰 |
| 레이아웃 | 상단 라벨(시리즈명) → 헤드라인 → 비주얼 → 하단 로고+핸들 고정 | 시리즈 인지 축적 |
| 규격 | 인스타 1080×1350(4:5) / 쇼츠 1080×1920(상단 320·하단 480 세이프존) / 블로그 커버 1600×900 | 시스템 렌더 스펙과 일치 |
| 한글 처리 | 전부 HTML→Chromium 렌더 (AI 확산 이미지에 한글 금지) | 시스템 원칙 |

## 1. 인스타그램 (@vittz_official, 팔로워 3.2만)

### 1-1. 벤치마크 분해

| 벤치마크 | 디자인 | 기획 | 내용 구성 |
|---|---|---|---|
| **오늘의집** | 실제 유저 집 사진, 텍스트 오버레이 최소, '평수·건물형태' 라벨 | UGC 큐레이션 + 참여장치(인테리어 월드컵, 집순이 빙고, 라이브 집들이) | 공간 전체 → 제품 태그. 콘텐츠가 곧 상품 진열 |
| **IKEA** | 뮤트 팔레트·여백·아늑한 조명으로 매장 경험 복제 | 비포애프터 캐러셀, 룸/제품군별 스토리 하이라이트, 릴스=스타일 핵 | 방 하나를 주제로 한 미니 스토리, #IKEAatHome UGC 해시태그 |
| **Govee(참고)** | 극적인 빛 연출 비포애프터 | 밈·트렌드 결합, 유저 세팅 리그램 | 15~30초 변화 데모 — '빛이 주인공' |
| **공간조명(경쟁)** | 제품컷·가격 소구 중심 | 프로모션 화력전(검색 스파이크형) | 특가 반복 — 차별화 여지 큼 |

**핵심 교훈**: 상위 업체는 전부 **"제품이 아니라 공간·변화를 판다"**. 제품컷 나열형 피드는
경쟁 조명몰의 문법이고, 플랫폼 상위권의 문법은 공간 스토리 + 참여 장치다.

### 1-2. 비츠 인스타그램 전략

**포지셔닝 선언**: "조명 하나로 달라지는 우리 집" — 피드 전체가 '조명 교체 비포애프터의
아카이브'로 읽히게 한다.

**주간 편성 (캐러셀 기준, 자동발행)**

| 요일(안) | 시리즈 | 캐러셀 구성 (6장 표준) |
|---|---|---|
| 월 | **공간 한 곳** (거실/주방/침실 로테이션) | ①공간 무드컷+헤드라인 ②문제(어두움/눈부심) ③해결 제품 ④연출 팁 ⑤스펙 요약(색온도·와트) ⑥CTA(프로필 링크·견적) |
| 수 | **조명 지식 카드** | ①질문형 헤드(주광색 vs 전구색?) ②~⑤개념 1장 1개 ⑥요약표 |
| 금 | **비츠라서** (딜리버리 후기/OV 디자인 스토리/AR) | ①후기 인용 헤드 ②~④스토리 ⑤서비스 안내 ⑥CTA |
| 일 | **시즌 기획** (02 문서 계절성 연동) | 시즌 소재 6장 (8월=실링팬 마감+가을 예고, 9~11월=교체) |

**디자인 규칙**: 1장차는 텍스트 30% 이하(도달 최적화), 시리즈별 상단 라벨 색 구분,
마지막 장은 항상 동일한 CTA 템플릿(브랜드 각인). 릴스 도입 시(자동화 2단계) 쇼츠 영상 재활용.

**해시태그**: 03 문서 시드 20개 중 게시물당 8~12개 — 대형(#인테리어) 3 + 중형(#거실등) 5 + 브랜드(#비츠조명) 2.

**KPI**: 도달, 저장수(핵심 — 저장이 알고리즘 가중 최대), 프로필 방문→링크 클릭. 팔로워보다 저장/도달 우선.

**자동화 매핑**: `render-cards.mjs` 캐러셀 → Instagram Graph API. 인사이트 수집 → learning.json →
시리즈별 성과로 편성 비중 자동 보정.

## 2. 유튜브 (구독 9,860 · 누적 1,870만 — 쇼츠 중심 보강)

### 2-1. 벤치마크 분해

| 벤치마크 | 전략 |
|---|---|
| **Home Depot** | 2,000개+ 하우투 영상, 2,500만+ 조회. "젊은 주택 소유자 70%가 DIY를 유튜브에서 배운다" — 하우투가 곧 신뢰·검색 자산. 프로젝트 단계별(계획→시공→마감) 시리즈화 |
| **IKEA USA** | Home Tour 시리즈 — 실제 집 방문 개조로 '영감 콘텐츠'의 정점 |
| **비츠 자체 데이터** | 1분 24~31초 정보영상 평균 1~2천 조회 vs **23초 셀프 설치 쇼츠 9.2만** — 포맷이 성과를 결정 |

**핵심 교훈**: 유튜브에서 비츠는 이미 답을 갖고 있다. **"30초 이내·행동 1개·검색어 제목"**
쇼츠가 채널의 성장 엔진이고, Home Depot 사례는 이걸 수백 개 쌓았을 때 무엇이 되는지 보여준다
(= 조명 하우투 검색의 기본값이 되는 것).

### 2-2. 비츠 유튜브 전략

**포지셔닝 선언**: "조명 문제, 30초면 해결" — 한국어 조명 하우투 검색의 1순위 채널.

**쇼츠 시리즈 설계 (주 2~3회 자동발행)**

| 시리즈 | 소재 풀 | 구성 (30초 표준) |
|---|---|---|
| **30초 셀프** | 방등/센서등/식탁등 교체, 커버 분리, 브라켓 | 0-3초 결과 먼저(교체 완료 컷) → 3-25초 3단계 과정 → 25-30초 안전 고지+브랜드 |
| **조명 응급실** | 잔광, 깜빡임, 안정기, 벌레 유입 | 0-3초 증상 공감("불 껐는데 희미하게 남죠?") → 원인 1줄 → 해결 |
| **비포애프터** (Govee 문법) | 간접조명, 무드등, 식탁 펜던트 | 0-2초 Before → 스위치 켜는 순간 → After 3컷 |
| **스펙 30초** | 색온도, 와트 계산, 플리커프리 | 화면 분할 비교(주광색 vs 전구색 같은 방) |

**제목 규칙**: 검색어 그대로 전진 배치 — "방등 교체 셀프", "LED 잔광 없애는 법".
설명란 첫 줄에 제품 링크, `ytTags`에 03 문서 키워드 매핑.

**KPI**: 쇼츠 조회수·시청 지속률(80%+ 목표), 검색 유입 비중, 채널 구독 전환.

**자동화 매핑**: 힉스필드 모션클립 배경 + 한글 오버레이 + BGM(`build-shorts-video.mjs`) →
YouTube Data API 업로드(공개 기본값 public). 기존 채널의 실사 영상과 병행 — 자동 쇼츠는
'지식·팁' 시리즈를 담당하고 실사 시공 영상과 충돌하지 않게 시리즈명으로 구분.

### 3-2. 비츠 네이버 블로그 전략

**포지셔닝 선언**: "조명 구매 전 검색하면 반드시 만나는 답" — SEO 본진. 6채널 중 **전환 기여 1순위**.

**원고 아키텍처 (1,500자 표준, AI 생성 → 담당자 복붙)**

```
제목: [키워드 전진배치] + 구체 숫자  예) "거실등 교체 비용, 5만원대로 끝내는 법 (2026 기준)"
도입 3줄: 검색 의도 공감 (문제 상황)
본문 1: 선택 기준 (표 1개 필수 — 네이버는 표·목록 구조 선호)
본문 2: 제품/해결책 (본문 이미지 2~3장 — 시스템이 렌더)
본문 3: 시공/설치 안내 (딜리버리 서비스 자연 연결)
마무리: 요약 3줄 + 안전 고지 + 링크
```

**소재 캘린더**: 03 문서 배치 5(교체·시공)·배치 2(공간별)를 9~11월에 집중, 시즌 역행 소재 금지.
연관검색어(키워드 도구 조회 결과)가 채워지면 롱테일 제목 풀을 월 단위로 갱신.

**KPI**: 검색 유입수, 상위 노출 키워드 수, 체류시간, 자사몰 클릭. 이웃수는 후행 지표.

**자동화 매핑**: 시스템이 원고+대표이미지(1600×900 가로 커버)+본문 이미지를 전부 생성,
대시보드 '네이버 도우미'에서 복사+다운로드 → 담당자 5분 게시. (발행 API 없음 — 04 문서)

## 4. 스레드 (신규 개설 권장)

### 4-1. 벤치마크 관찰

- 스레드는 브랜드 계정도 **'사람처럼 말하는' 텍스트**가 도달을 만든다. 완성형 광고 문구보다
  경험담·질문형·목록형 짧은 글이 강함. 국내 인테리어 계정들도 '오늘의 꿀팁 한 줄' 문법이 주류.
- 인스타 계정 연동으로 개설 비용 제로, 초기 팔로워 시드 확보 가능.

### 4-2. 비츠 스레드 전략

**포지셔닝 선언**: "조명 가게 사장님의 혼잣말" — 6채널 중 가장 사람 냄새 나는 톤.

**포맷 3종 (일 1회 로테이션, 자동발행)**
1. **한 줄 팁**: "전구색 침실에 쓰면 잠이 잘 오는 이유 —" + 2줄 설명 + 이미지 1장
2. **질문 유도**: "거실등, 하얀 불 vs 노란 불 어느 쪽이세요?" (댓글 유도 — 알고리즘 가중)
3. **비하인드**: 설치 기사님 에피소드, 매장 일상 (딜리버리 후기 재가공)

## 5. 구글 블로그 (신규 · Blogger)

**역할**: 네이버 밖 검색(구글) 흡수 + 유튜브 쇼츠 설명란·해외 유입의 착지 페이지.

  네이버 원고를 그대로 복제하지 않고 FAQ 블록("방등 교체 비용은?" 3문답)을 추가한 리라이트로 운영.

- KPI: 구글 검색 노출·클릭(서치콘솔), 쇼츠→블로그 유입.
- 자동화 매핑: Blogger API v3 완전 자동발행. 주 1~2회.
