## 🔲 대표님이 하실 일

### 1. (완료) 데이터 백필 — 제가 직접 31일치 채우고 로그로 검수했습니다 ✅
- **네이버 검색 키워드 리포트**: 수집 성공(하루 655건 = 약 131개 키워드/광고그룹). 광고 히스토리
  탭 → **네이버 검색(키워드)** / **네이버 플레이스** 에서 광고비 소진 순으로 보입니다.
- **광고 전환수(GA4)**: GA4 400 오류(keyEvents/conversions 중복) 해결 → 전환수·전환율 정상 수집.
  > 광고 카드 전환수가 그래도 0으로 보이면, GA4에 "키 이벤트(전환)"가 설정돼 있지 않은 것입니다.
  > 👉 GA4 → 관리 → 이벤트에서 **상담신청/전화클릭 등**을 "핵심 이벤트(키 이벤트)"로 표시하면
  > 다음 수집부터 그 값이 광고 채널별 전환수로 잡힙니다. (코드/연동은 이미 끝났고, GA4 설정만 남음)
- 대시보드는 푸시 시 Render가 자동 재배포합니다(수 분). 새 채널 탭이 바로 보입니다.

### 2. (선택) 경쟁사 "네이버 쇼핑 검색"만 아직 401 — 네이버 앱에 "검색" API 추가
현재 경쟁사 트렌드(데이터랩)는 되는데, **쇼핑 검색 결과**만 401이 납니다.
네이버 개발자 앱에 **"검색" API가 안 켜져 있어서**입니다(데이터랩만 켜진 상태).

1. 👉 https://developers.naver.com/apps/#/list → 쓰시던 앱(`dbrick-competitor`) 클릭
2. **API 설정** 탭 → **사용 API** 에서 **"검색"** 추가 → 저장
3. 이미 등록된 `DBRICK_NAVER_CLIENT_ID/SECRET` 그대로 쓰므로 시크릿 재등록 불필요
4. 다음 자동 수집(내일 08:00)부터 경쟁사 쇼핑 검색도 채워집니다

> 이건 "있으면 좋은" 부가 기능입니다. 안 해도 광고/전환/방문자/지역/경쟁사 트렌드는 전부 정상입니다.

### 3. (선택) 경쟁사 소재/포스팅 이미지를 대시보드 안에 넣고 싶을 때 — 구글시트 1개
경쟁사 탭 상단 "지정 현황"의 **홈페이지·인스타·메타 광고(라이브)·구글 광고** 버튼은 이미
동작합니다(클릭하면 각 라이브 페이지로 바로 이동 — 항상 최신). 여기에 더해 **인스타 게시물·광고
소재 이미지와 좋아요/댓글 수치를 대시보드 안에 카드로** 보고 싶으시면 구글시트 1개만 연결하면 됩니다.

1. 구글시트 새 탭을 만들고 첫 줄(헤더)에: `경쟁사 | 플랫폼 | 게시일 | 이미지URL | 좋아요 | 댓글 | 캡션 | 링크`
   - 플랫폼: `instagram` / `meta` / `google` 중 하나 · 게시일: `2026-07-02` 형식
   - 이미지URL: 게시물/소재 이미지 주소(공개 접근 가능한 URL)
2. 지역현황 시트처럼 **서비스계정 이메일에 뷰어 공유** (같은 계정 재사용).
3. 그 시트의 `sheet_id`/`gid` 를 `config/sources.yaml` 의 `competitor_media:` 에 넣기(제게 링크 주시면 제가 넣습니다).
4. 넣으면 경쟁사 탭에 **선택 기간에 게시된** 소재/포스팅이 이미지 카드로 뜹니다(좋아요·댓글 포함).

> 시트를 안 넣어도 딥링크 버튼(원클릭 이동)은 그대로 동작합니다. 시트는 "이미지를 대시보드 안에
> 박제해두고 싶을 때"만 필요합니다.
