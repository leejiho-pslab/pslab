| 핸들 | 상태 |
|---|---|

**`@keek_crew` → `@keek_kr` 핸들 변경이 확정됐다.** 근거 2가지:

2. **`@keek_jp`의 바이오에 아직 `@keek_crew` 멘션이 남아 있다** (미갱신 흔적)

> 검색엔진 색인은 아직 옛 핸들(`keek_crew`, 42K)로 남아 있다. 실제 수치는 아래가 정확하다.

## 2. 성과 실측 (최근 50건 표본)

| 지표 | @keek_kr | @keek_jp |
|---|---|---|
| 평균 좋아요 | **33.8** | 10.5 |
| 평균 댓글 | 2.5 | 0.1 |
| 최고 좋아요 | 101 | 43 |
| **팔로워 대비 참여율** | **0.096%** | **0.196%** |
| 포맷 | REELS 40 / FEED 10 | FEED 29 / REELS 21 |
| 표본 기간 | 2025-12-31 ~ 2026-07-21 | 2025-12-12 ~ 2026-07-22 |

### 냉정한 진단

**참여율 0.096%는 매우 낮다.** 팔로워 37,798명인데 게시물당 좋아요가 평균 34개다. 통상 브랜드 계정 기준선(1~3%)의 **1/10~1/30 수준**이다.

가능한 원인 (검증 필요):
1. **팔로워 품질** — 과거 이벤트·팔로우 유도로 모인 비활성 팔로워 비중이 높음
2. **핸들 변경 여파** — `keek_crew` → `keek_kr` 전환 시점의 도달 리셋 / 기존 팔로워 이탈
3. **콘텐츠-오디언스 불일치** — 아래 3-2 참조

> 릴스는 좋아요보다 **재생수**가 실질 지표다. 재생수를 못 봐서 "노출 자체가 안 나오는 것"인지 "노출은 되는데 반응이 없는 것"인지 아직 구분 못 한다. → **계정 인사이트 확인이 최우선 과제.**

## 3. 콘텐츠 구조 (실측 50건)

### 3-1. 발행 패턴

**요일 분포 (KR)**
```
금 12 ████████████
월 10 ██████████
화  9 █████████
수  9 █████████
목  8 ████████
토  2 ██
일  0
```
평일 집중, **금요일 최다**. 주말은 사실상 비운다.

**시간 분포 (KST, KR)** — 17시(9건)·18시(8건) 최다, 다음 11시(6건)·10시(5건).
→ **퇴근 직전 시간대**에 몰아 넣는 패턴. 다만 최고 성과 게시물(♥101)은 **화요일 12시**였다.

**월별 발행량 (KR)**
```
2026-01  8
2026-02  4
2026-03 11  ← 피크
2026-04 10
2026-05  6
2026-06  6
2026-07  4  ← 감소
```
3~4월 피크 후 **발행량이 절반으로 줄었다.** 주 2~3회 → 주 1회 수준. 일관성이 무너진 구간이다.

### 3-2. 캡션 톤 — 여행에서 감성으로 이동했다

| 유형 | 비중 | 실례 |
|---|---|---|
| **감성·정서 카피** | 최다 | "지친 하루를 마치고," / "출근길 지하철," / "언제든, 편안하게." / "이동이 길어질수록" / "같은 자세로 버티는 하루," |
| **팝업·유통 공지** | 다수 | "🎉 신라면세 서울점(장충점) OPEN!" / "#롯데백화점 #명동 본점 POP-UP OPEN 🎊" / "keek DAEJEON POP-UP" / "GOODBYE TIMES SQUARE!" |
| **신제품 소개** | 다수 | Air Brief Bag V2 / Air Safety Harness / Blowfish Bag / Pillow O V2 / Air bucket bag |
| **이벤트·시즌** | 소수 | `#keekrun` / "대한민국의 승리를 응원하며," / "Happy Dog Day!" |

**핵심 관찰**: 예전 계정의 대표 훅이었던 *"3초만에"*, *"여권보다 작은"* 같은 **기능 실증형 훅이 최근 50건에는 사실상 없다.** 딱 1건("여권보다 작게," 2026-05-06, ♥28)뿐이다.

대신 "지친 하루를 마치고"가 최고 성과(♥101)를 냈다. 다만 **표본이 감성 콘텐츠로 치우쳐 있어 기능형과 직접 비교가 불가능하다.** → A/B로 확인해야 할 1순위 가설.

### 3-3. 해시태그 — 사실상 쓰지 않는다 ⚠️

**@keek_kr 50건의 해시태그 전체 빈도**
```
keek 6 · keekrun 2 · pillowdy 2 ·
키크/필로우디/Neckpillow/AirFlow/롯데백화점/명동/직장인/루틴/
LifeStyleTech/성수/롯데면세점  각 1회
```
50개 게시물 중 해시태그가 붙은 건 **10건 남짓**. 대부분 아예 없다.

**@keek_jp와 비교하면 격차가 명확하다**
```
pillowdy 29 · keek 25 · hoodies 6 · keekjp 5 · choosebaseshibuya 4 ·
空港ファッション(공항패션) 4 · ロフト 3 · loftjapan 3 · springsale 3 ...
```
JP는 거의 모든 게시물에 브랜드+카테고리+상황 태그를 붙인다. **팔로워는 KR의 1/7인데 참여율은 2배다.**

→ KR 계정의 **가장 크고 가장 쉬운 개선점.** 탐색 탭·해시태그 유입 경로를 스스로 닫아두고 있다.

**패턴**: 상위 7건 전부 **릴스**. 상위권 캡션은 예외 없이 **"쉼/휴식"** 을 말한다. 팝업 공지도 상위권에 든다.

**댓글 이상치**: 2026-06-19 축구 국가대표 응원 게시물(♥33)에 **댓글 35개** — 표본 전체 댓글의 절반. 참여형 이벤트가 댓글을 만든다는 증거지만, 브랜드/제품과 무관해 자산으로 쌓이지 않는다.

**좋아요 0 게시물 5건** (2026-03~04 집중) — 좋아요 숨김 설정이거나 실제 0. JP는 2025-12~2026-04 구간 대부분이 0이라 **숨김 설정 가능성이 높다.** 이 구간 수치는 참고만 할 것.

### 3-5. 일본 계정 (참고할 점 / 하지 말 점)

**참고할 점**
- 바이오에 효익·판매처를 다 담음
- 해시태그를 매 게시물에 붙임 (`#空港ファッション` 같은 상황 태그 포함)
- 취급점 정보를 반복 공지(로프트 7개점, CHOOSEBASE SHIBUYA) — 오프라인 전환 설계
- 참여율 0.196%로 KR의 2배

**하지 말 점**
- **같은 캡션을 12건 이상 그대로 복붙**했다 ("Pillowdyは「いつでもどこでもパーフェクトな憩い」を提案する機能性衣類です。"로 시작하는 게시물이 표본에만 12건). 성과 편차 없이 평탄하게 낮다.
- 바이오에 폐기된 `@keek_crew` 멘션이 남아 있음 (관리 누락)

## 6. 우선순위 액션 (근거 기반)

1. **해시태그 운영 도입** — 가장 싸고 확실한 개선. JP가 같은 브랜드·같은 제품으로 2배 참여율을 낸다. 브랜드(#keek #키크 #필로우디) + 카테고리(#목베개 #경량바람막이) + 상황(#공항룩 #출근길 #여행필수템) 3층.
2. **바이오 재작성** — `keek | Lifestyle Tech brand`는 무엇을 파는지 안 알려준다. JP처럼 "3초에 목베개가 되는 후디"를 넣는다.
3. **기능 실증형 릴스 부활 + A/B** — 감성형만 남아 비교가 불가능하다. "3초", "150g", "여권보다 작게", "안 쓸 땐 티 안 남"을 각 1편씩 만들어 감성형과 성과를 비교.
4. **발행량 회복** — 3월 11건 → 7월 4건. 최소 주 2회로 복원.
5. **인사이트 확보** — 릴스 재생수 없이는 "노출이 안 되는지 / 반응이 안 오는지" 구분 불가.
6. **재고와 콘텐츠 정합** — 최근 50건에 분석 대상 2개 제품 단독 게시물이 사실상 없다. 그런데 윈드브레이커는 **3,055장이 쌓여 있고**, 베스트는 **3개 조합이 마이너스 재고**다. **판매 압력과 콘텐츠가 정반대로 어긋나 있다.** (→ `product-windbreaker-v3.md` §3, `product-utility-nylon-vest.md` §3)
