## 5. 기능 정리

1. **목베개 변환 (Pillowdy Air Tech)** — 외부 가슴 포켓 공기주입구 → 3초 팽창, 손쉬운 탈기, PE 밸브 분리 세척.
2. **메쉬 안감 통기성** — 이 제품의 *차별 포인트*. 안감이 메쉬라 통기·활동성이 좋아 **운동 시에도 착용 가능**하다고 공식이 명시.
3. **생활 방수 · 방풍** — PU 코팅 기능성 원단.
4. **속건 · 방오(강성)** — 나일론 원단 특성.
5. **내구성** — YKK 지퍼.
6. **스타일 조절** — 후드 뒷편·밑단 엘라 스트링 → 기후·기호에 맞춘 실루엣, **고프코어 무드** 연출.
7. **레이어드 유틸리티** — 여름·가을 레이어드용. "반팔에 걸치기도 좋고 겨울엔 긴팔에 툭 걸치기 좋은 아우터". [리뷰]
