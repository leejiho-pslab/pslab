# 접근 권한 설정 가이드 (실제 소요 3분)

콘텐츠 제작을 시작하기 전에, 제가 **자사몰과 인스타그램 데이터를 직접** 볼 수 있게 만드는 설정입니다.

---

## 먼저: 지금 뭐가 되고 뭐가 안 되나

| 필요한 것 | 지금 | 설정 후 |
|---|---|---|
| 자사몰 상품 정보(가격·옵션·재고·상세카피) | ⚠️ **되긴 됨** — GitHub Actions 우회, 1회 40초 | ✅ 제가 즉시 직접 조회 |
| 상세페이지 **이미지**(사이즈표 등) | ❌ 못 봄 | ✅ 볼 수 있음 |
| 인스타 게시물·좋아요·댓글·캡션 | ⚠️ **되긴 됨** — Actions 우회 | ✅ 제가 즉시 직접 조회 |
| 인스타 **릴스 재생수·도달·저장** | ❌ 못 봄 | ❌ **여전히 못 봄** → 2단계 필요 |
| 라이브 운영 대시보드 | ❌ 못 봄 | ✅ 볼 수 있음 |

> **중요**: 지금도 데이터는 나옵니다. 다만 매번 GitHub Actions를 돌려서 로그를 읽는 방식이라 **한 번 확인에 40초~1분**이 걸립니다.
> 콘텐츠를 만들면서 "이 컬러 재고 얼마지?", "이 게시물 반응 어땠지?"를 수십 번 확인해야 하는데, 그때마다 1분씩 쓰면 작업이 안 됩니다. 그래서 1단계를 권합니다.

---

# 1단계 — 네트워크 허용 (필수, 3분)

## 하는 방법

1. **https://claude.ai/code** 접속
2. 왼쪽에서 **환경(Environments)** 메뉴로 이동
3. 지금 이 세션이 쓰는 환경을 찾아 **편집(Edit)** 클릭
   → `Update cloud environment` 창이 열립니다
4. 창 안에서 **`Network access`** 선택기를 찾습니다
5. 현재 값 **`Trusted`** → **`Custom`** 으로 변경
6. **`Allowed domains`** 입력칸에 아래를 **그대로 복사해서 붙여넣기** (한 줄에 하나씩)

```
keek-line.com
*.keek-line.com
*.cafe24api.com
api.cafe24.com
cafe24img.poxo.com
graph.facebook.com
keek-ops-dashboard.onrender.com
openapi.naver.com
```

7. **`Also include default list of common package managers`** 체크박스를 **반드시 켠 상태로 유지** ← 이걸 끄면 npm·pip 설치가 깨집니다
8. 저장

## 각 도메인이 왜 필요한지

| 도메인 | 용도 |
|---|---|
| `keek-line.com`, `*.keek-line.com` | 자사몰 상품 상세페이지 직접 열람 |
| `cafe24img.poxo.com` | **상세페이지 이미지** (사이즈표·기능 설명 이미지가 여기 있음) |
| `api.cafe24.com`, `*.cafe24api.com` | Cafe24 어드민 API (재고·주문·매출) |
| `graph.facebook.com` | **인스타그램 데이터** (Meta 서버. instagram.com이 아님) |
| `keek-ops-dashboard.onrender.com` | 이미 만들어둔 운영 대시보드 |
| `openapi.naver.com` | 네이버 검색·쇼핑·데이터랩 (경쟁·검색 트렌드) |

## ⚠️ `instagram.com`은 넣지 마세요

넣어도 소용없습니다. 인스타그램은 로그인 안 한 접근을 막기 때문에 도메인을 열어도 프로필을 읽을 수 없습니다.
**인스타 데이터는 `graph.facebook.com`(Meta 공식 API)으로 가져옵니다.** 이미 그렇게 뽑아냈고, 위 목록에 포함돼 있습니다.

## 권한이 없다면

환경 설정은 계정/조직 관리자만 바꿀 수 있는 경우가 있습니다. 그럴 땐 관리자에게 **위 8줄과 이 문단만 그대로 전달**하시면 됩니다.

참고 문서: https://code.claude.com/docs/en/claude-code-on-the-web

# 2단계 — 인스타 릴스 재생수 확보 (선택, 콘텐츠 품질에 큰 영향)

## 왜 필요한가

지금 확인된 keek_kr 참여율은 **0.096%** 입니다. 그런데 이 숫자만으로는 원인을 모릅니다.

- **노출 자체가 안 나오는 것**인지 (→ 해시태그·발행시간 문제)
- **노출은 되는데 반응이 없는 것**인지 (→ 콘텐츠·훅 문제)

이 둘은 해결책이 정반대입니다. **릴스 재생수 하나만 있으면 바로 구분됩니다.**
지금 API로는 좋아요·댓글까지만 나오고 재생수·도달·저장은 안 나옵니다. 계정 소유자 권한이 필요하기 때문입니다.

## 3가지 방법 — 쉬운 순서

### 방법 A. 스크린샷/CSV (0분, 지금 당장 가능) ⭐ 추천

keek 인스타 계정에 로그인할 수 있는 분에게 부탁하면 됩니다.

1. 인스타그램 **모바일 앱** → 프로필 → **프로페셔널 대시보드**
2. **인사이트** → 기간 **최근 90일**
3. 아래 3가지를 캡처
   - 계정 도달·팔로워 증감 요약
   - **팔로워 데모그래픽** (성별·연령·지역·활동 시간대)
   - **게시물별 인사이트** — 조회수 순 정렬 상위 20개
4. 저에게 이미지로 주시면 제가 읽고 분석에 반영합니다

가장 빠르고, 오늘 바로 됩니다.

### 방법 B. keek 인스타를 Meta 비즈니스에 연결 (10~20분, 자동화됨)

한 번 해두면 이후로는 제가 언제든 자동으로 가져옵니다.

**전제 조건** — keek 인스타 계정이
- **비즈니스 또는 크리에이터 계정**이어야 하고
- **페이스북 페이지에 연결**되어 있어야 합니다

**순서**
1. `business.facebook.com` → **비즈니스 설정**
2. **계정 → Instagram 계정**에서 keek 계정 추가
3. **사용자 → 시스템 사용자** → 토큰 생성
   권한: `instagram_basic`, `instagram_manage_insights`, `pages_show_list`, `pages_read_engagement`
   (장수명 토큰 권장 — 60일)
4. GitHub 저장소 → **Settings → Secrets and variables → Actions → New repository secret**
   - 이름: `KEEK_INSTAGRAM_ACCESS_TOKEN` / 값: 발급받은 토큰
   - 이름: `KEEK_INSTAGRAM_IG_USER_ID` / 값: keek 인스타 계정의 IG User ID
5. 저에게 알려주시면 수집 스크립트에 붙여서 릴스 재생수·저장·도달까지 자동 수집합니다

### 방법 C. keek 측 담당자에게 요청

keek 마케팅 담당자가 직접 위 B를 하거나, A의 인사이트를 주기적으로 공유하는 방식입니다.

# 3단계 — 상세페이지 사이즈표 (선택, 1분)

공식 사이즈표(XS~XXL 총장·어깨·가슴·소매)가 **텍스트가 아니라 이미지**로 되어 있습니다.
1단계를 하면 제가 이미지 URL을 열 수는 있지만, 이미지 속 숫자를 읽으려면 화면에 띄워야 합니다.

**가장 빠른 방법**: 상품 페이지에서 사이즈표 이미지만 캡처해서 주세요.
- [윈드브레이커 V3](https://keek-line.com/product/keek-pillowdy-uv-light-windbreaker-v3/1833/)
- [유틸리티 베스트](https://keek-line.com/product/keek-pillowdy-utility-nylon-vest/1793/)

또는 Cafe24 어드민 → 상품관리 → 상품번호 `1833`/`1793` → 상세설명에서 확인.

# 설정 끝나면

저에게 **"접근 확인해줘"** 라고 말씀만 주세요. 제가 바로 아래를 검증해서 결과를 보고드립니다.

```
✓ keek-line.com 상품 1833/1793 직접 열람
✓ Cafe24 API 재고 조회
✓ Graph API 인스타 데이터 조회
✓ 상세 이미지 접근
```

문제가 있으면 어느 도메인이 막혔는지 정확히 짚어드립니다.
