## 4. 상세 기능 (공식 카피 기반)

자사몰 V2 페이지 원문(V3도 동일 골격):

> "UV 가공 원단으로 UPF 50+ 자외선 차단 기능을 제공하는 필로우디 경량 바람막이 입니다. 사용하지 않을 때엔 **왼쪽 주머니를 뒤집어 패커블 형태**로 만들 수 있어 여행, 캠핑 시 수납에 용이하며 **주머니 지퍼**가 있어 소지품을 안전하게 보관할 수 있습니다. **후드와 밑단에 조절 스트링**을 적용하여 시야 확보 및 갑작스러운 기후 대처에 다양한 활용이 가능한 제품입니다. **공기주입구로…**"

정리하면 기능 축은 5개다.

1. **목베개 변환 (Pillowdy Air Tech)** — 외부 가슴 포켓 공기주입구에 숨을 불어넣어 3초(공식)~5초(보도)에 후드가 목베개로 팽창. 탈기 간편. 밸브는 PE 소재, 분리 세척 가능.
   - 실사용: 가슴 지퍼에서 호스가 나오며, 성인 여성 기준 **깊은 숨 3~4번**이면 충분. [리뷰]
2. **UPF 50+ 자외선 차단** — 여름 아우터로서의 존재 이유.
3. **패커블 수납** — 왼쪽 주머니를 뒤집어 자체 파우치화. 여행·캠핑 수납.
4. **지퍼 포켓** — 이동 중 소지품 낙하 방지.
5. **후드·밑단 조절 스트링** — 시야 확보, 급변 기후 대응, 실루엣 조절.
