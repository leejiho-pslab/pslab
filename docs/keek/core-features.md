# A. 제품의 핵심 기능

## A-0. 모든 것의 뿌리 — Pillowdy Air Tech

```
Pillow(베개) + Hoodie(후드) = Pillowdy
  └ 외부 가슴 포켓의 공기주입구에 숨을 불어넣음
      └ 3초(공식) ~ 5초(보도) 만에 원단이 부풀어 목베개로 변형
          └ 탈기도 손쉬움 / 밸브는 인체무해 PE, 분리 세척 가능
              └ 공기량 조절로 지지 강도 커스터마이즈 (3D 인체공학 패턴)
                  └ V3부터 자체 개발 '필로우 키트(Pillow Kit)'로 목 지지력 강화
```

**이것 하나만 이해하면 keek의 모든 제품이 설명된다.** 후디·윈드브레이커·베스트·재킷은 전부 "이 기술을 어떤 바디에 얹었는가"의 변주다.

브랜드가 이 기술에 붙인 의미:
- 친환경 — 다운/폼이 아니라 **공기**를 충전재로 씀
- 특허 — '지지대가 포함된 인체 친화적 날개형 에어 쿠션'
- 실적 — 누적 판매 **10만 장** 돌파

## A-2. 한 문장 포지셔닝

- **Windbreaker V3** → *"150g, 여권보다 작게 접히는 UPF 50+ 바람막이. 그런데 후드가 3초 만에 목베개가 된다."*
  - 지배 키워드: **초경량 / 패커블 / 자외선**
  - 주 무대: 장거리 비행, 공항, 여름~가을 여행
- **Utility Nylon Vest (Mesh)** → *"팔이 자유롭고 안감이 메쉬라 운동까지 되는 목베개 조끼."*
  - 지배 키워드: **통기 / 활동성 / 레이어드 / 고프코어**
  - 주 무대: 간절기 레이어드, 운동, 캠핑, 면세점 대표 진열 상품

## A-3. 자주 틀리는 지점 (콘텐츠 제작 시 주의)

1. **V2와 V3 혼동** — 둘 다 159,000원, 이름 거의 동일. V3의 식별자는 **품번 K0HJK001 / 4컬러(라이트블루 포함) / 필로우 키트 / 립스탑 / 정전기 방지**.
2. **베스트 3종 혼동** — `Mesh lining`(P0FVT301, 149,000원) / `Single-layer 안감X`(K0HVE201, 149,000원) / `아로치카 콜라보`. **가격이 같으므로 차이는 안감뿐**.
3. **"3초 vs 5초"** — 공식 카피는 3초, 언론 보도는 5초. 공식 자산에는 **3초**를 쓴다.
4. **UPF 50+는 윈드브레이커의 속성** — 베스트에 갖다 붙이면 안 된다.
5. **사이즈 폭 차이** — 윈드브레이커 XS~XXL vs 베스트 M/L. "누구나 맞는 사이즈"는 윈드브레이커에만 쓸 수 있는 말.

# B. 인스타그램 계정의 핵심 기능

계정이 실제로 수행 중인 기능은 5개다. (근거: `instagram.md`)

## B-1. 기능 ① 발상 전달 (Demo Engine)
- 제품이 **부풀어 오른다**. 정지 이미지로 설명 불가 → 릴스가 필수.
- 계정의 1차 존재 이유는 "이런 게 있다"는 **시연**이다.
- 훅 문법 3종: **숫자·속도**("3초만에") / **크기 비교**("여권보다 작은") / **반문**("설마 아직도 목베개를 따로 챙겨다녀요?")

## B-2. 기능 ② 습관 재정의 (Category Reframing)
- 바람막이끼리 비교시키지 않는다. **"목베개를 따로 챙기는 습관"** 을 문제로 세운다.
- 이 프레임이 성립해야 15만원대 가격이 납득된다. 가격 방어의 핵심 장치.

## B-3. 기능 ③ 커머스 공지 (Conversion Layer)
- 재입고("#필로우디 베스트 재입고✨"), 신제품, 컬러 추가 등 피드 게시물.
- 릴스로 들어온 신규 유입을 **구매 시점 정보로 전환**시키는 층.

## B-4. 기능 ④ 오프라인 증폭기 (Offline Amplifier)
- 성수 플래그십 "Opening D-5" 카운트다운 릴스 → 팝업 방문 유도 → 방문 UGC 폭증.
- 팝업 체험 이벤트(시착 시 양말, 에어볼 추첨)가 **UGC 생산 장치**로 설계되어 있음.
- 온라인 콘텐츠 ↔ 오프라인 체험이 서로를 먹여 살리는 루프.

## B-5. 기능 ⑤ UGC 허브 (Creator Hub)
- 팔로잉 2개. 상호 팔로우 성장이 아니라 **협찬 크리에이터가 만든 리치를 수렴**하는 허브.
- `#협찬` `#광고` + `@keek_crew` 멘션 UGC가 인스타·블로그 양쪽에서 지속 생산.
- 셀럽 착용(김재중·손호영 등)이 검색 트래픽을 만들고, 그 검색이 다시 계정으로 흐름.
