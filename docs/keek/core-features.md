# A. 제품의 핵심 기능

## A-0. 모든 것의 뿌리 — Pillowdy Air Tech

```
Pillow(베개) + Hoodie(후드) = Pillowdy
  └ 외부 가슴 포켓의 공기주입구에 숨을 불어넣음
      └ 3초(공식) ~ 5초(보도) 만에 원단이 부풀어 목베개로 변형
          └ 탈기도 손쉬움 / 밸브는 인체무해 PE, 분리 세척 가능
              └ 공기량 조절로 지지 강도 커스터마이즈 (인체공학 3D 패턴)
                  └ V3 = 이전 KIT(CAH11F)에 굴곡 추가 → 2차원 입체에서 3차원 입체로
                      └ 공기를 빼면 목베개 기능이 전혀 안 보여 스타일 유지 ★
```

**이것 하나만 이해하면 keek의 모든 제품이 설명된다.** 후디·윈드브레이커·베스트·재킷·가방(Blowfish Bag, Air Brief Bag)까지 전부 "이 에어 기술을 어떤 바디에 얹었는가"의 변주다.

### ★ 가장 저평가된 문장

자사몰 원문:
> "공기를 빼 기능을 사용하지 않을 때에는 **목베개 기능이 전혀 보이지 않아 스타일을 유지시켜줍니다.**"

목베개 일체형 의류의 최대 약점은 "안 쓸 때 목이 튀어나와 이상하다"는 것이다. keek는 그 약점이 없다. 그런데 **기사·리뷰·인스타 어디에도 이 논거가 부각돼 있지 않다.** 콘텐츠 앵글 1순위.

### 브랜드가 붙인 의미
- **친환경** — 다운/폼이 아니라 **공기**를 충전재로 씀
- **특허** — '지지대가 포함된 인체 친화적 날개형 에어 쿠션'
- **실적** — Pillowdy 누적 판매 **10만 장** 돌파 (2025.12 보도)

## A-3. 자주 틀리는 지점 ⚠️

1. **UV 차단·패커블은 윈드브레이커 전용.** 베스트 상세에는 두 섹션이 아예 없다. 혼용 금지.
2. **UPF 50+는 V3 자사몰 카피에 없다.** V2 카피와 언론에만 있다. V3에 쓰려면 브랜드 확인.
3. **`Ribstop`은 자사몰 오타.** 정확한 표기는 `Ripstop / 립스탑`.
4. **V2와 V3 혼동** — 둘 다 159,000원, 이름 거의 동일. V3 식별자는 **P0000CSN / K0HJK001 / 4컬러(L.Blue 포함) / XS~XXL / 3D 업그레이드 키트**.
5. **베스트 3종 혼동** — Mesh lining(P0000CQZ) vs Single-layer 안감X(K0HVE201) vs 아로치카 콜라보. **가격이 같으므로 차이는 안감뿐.**
6. **"3초 vs 5초"** — 공식 카피는 **3초**. 언론은 5초. 공식 자산에는 3초.
7. **사이즈 폭 차이** — 윈드브레이커 XS~XXL vs 베스트 M/L. "누구나 맞는 사이즈"는 윈드브레이커에만 쓸 수 있다.
