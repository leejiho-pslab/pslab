# 캡컷 연동 가이드 — 파일럿 절차서

> 목적: 에이전트(저)가 만든 릴스 편집본을 **캡컷에서 열어 손볼 수 있게** 연결한다.
> 이 문서는 **연결이 가능한지 먼저 확인**하는 절차다. 코드는 아직 없다.
> 결정 배경 → [ADR-0015](../.claude/skills/sns채널-자동화/adr/0015-캡컷-연동-경로.md)

---

## 한눈에: 왜 "확인"부터 하나

캡컷에는 **편집용 공개 API가 없다.** 외부에서 캡컷을 조종할 방법이 공식적으로는 없다는 뜻이다.

쓸 수 있는 접점은 하나뿐이다. 캡컷은 작업 중인 프로젝트를 PC 안에 **드래프트(초안) 폴더**로
저장하는데, **그 폴더를 우리가 직접 만들어 넣으면** 캡컷을 켰을 때 "이미 편집돼 있는 프로젝트"로
보인다. 이게 곧 "에이전트가 직접 편집한 결과"다.

문제는 이 폴더 형식이 **비공식**이라는 것. 캡컷이 버전을 올리면서 이 파일을 **암호화**해 버리면
그 순간 이 경로가 통째로 막힌다. 실제로 중국판(剪映)은 6.0부터 암호화됐다.

그래서 **코드를 쓰기 전에 소장님 PC의 캡컷이 어느 쪽인지 확인**하는 게 먼저다.
확인은 10분이면 끝나고, 결과에 따라 진행 여부가 갈린다.

---

## 지금까지 파악된 것

| 구분 | 버전 | 드래프트 파일 | 연동 |
|---|---|---|---|
| **캡컷 국제판** (CapCut) | 6.x ~ 9.x | 일반 JSON (평문) | **가능** ✅ |
| 중국판 剪映 (JianYing) | 5.9.0 | 일반 JSON (평문) | 가능 ✅ |
| 중국판 剪映 (JianYing) | 6.0 이상 | 암호화된 덩어리 | **불가** ❌ |

소장님이 쓰시는 게 **캡컷 국제판이면 최신 버전이어도 될 가능성이 높다.**
다만 위 표는 2026년 5월 기준 커뮤니티 검증 결과라서, **직접 확인이 필요**하다.

> ⚠️ **주의**: 剪映 6.0 이상에서 드래프트를 한 번 저장하면 **평문으로 되돌릴 수 없다.**
> 확인 작업은 **중요한 프로젝트가 아닌 연습용 프로젝트**로 하시기 바란다.

## 파일럿 — 소장님이 하실 일 (10분)

### 1단계. 캡컷 버전 확인

캡컷 실행 → 우측 상단 **설정(톱니바퀴)** → **정보 / About** 에서 버전 번호를 확인한다.

적어둘 것: **① 제품 이름**(CapCut / 剪映 둘 중 무엇인지) **② 버전 번호**(예: 7.5.0)

### 2단계. 연습용 프로젝트 하나 만들기

캡컷에서 **새 프로젝트**를 만들고, 아무 영상이나 하나 올린 뒤 **자막을 한 줄** 넣고 닫는다.
(내용은 상관없다. 폴더 구조를 보려는 것뿐이다.)

프로젝트 이름을 기억하기 쉽게 `pslab-test` 같은 걸로 해두면 3단계가 편하다.

### 3단계. 드래프트 폴더 열기

**윈도우**

1. 키보드 `윈도우키 + R`
2. 아래를 붙여넣고 엔터

```
%LOCALAPPDATA%\CapCut\User Data\Projects\com.lveditor.draft
```

**맥**

1. Finder → 메뉴 **이동** → **폴더로 이동…** (단축키 `⌘ + ⇧ + G`)
2. 아래를 붙여넣고 엔터

```
~/Movies/CapCut/User Data/Projects/com.lveditor.draft
```

이 안에 방금 만든 프로젝트 이름의 폴더가 있을 것이다. 그 폴더를 연다.

### 4단계. ★ 핵심 — 평문인지 암호화인지 확인

폴더 안에서 **`draft_content.json`** 파일을 찾는다.
(맥은 `draft_info.json` 또는 `draft_meta_info.json` 으로 보일 수 있다. 이름이 다르면 **보이는
그대로 알려주시면 된다.**)

이 파일을 **메모장**(윈도우) 또는 **텍스트 편집기**(맥)로 연다.
용량이 커서 잠깐 버벅일 수 있는데 정상이다.

**맨 앞 몇 줄을 보고 판단한다:**

| 화면에 보이는 것 | 판정 |
|---|---|
| `{"canvas_config":{"height":1920,...` 처럼 **읽히는 영문 단어**들 | **평문 ✅ — 연동 가능** |
| 알아볼 수 없는 기호·깨진 글자 덩어리 | **암호화 ❌ — 연동 불가** |

### 5단계. 알려주실 것

1. 제품 이름 + 버전 번호 (1단계)
2. 4단계 판정 — **평문인지 암호화인지**
3. 드래프트 폴더 안에 있던 **파일·폴더 이름 목록** (스크린샷이면 더 좋다)

## 결과에 따라 무엇이 달라지나

### 평문이면 → 연동 진행

이미 만들어 둔 **타임라인 IR**(릴스 대본을 "몇 프레임에 무슨 클립·무슨 자막"으로 확정한 데이터)을
캡컷 드래프트 형식으로 변환하는 코드 한 단계만 붙이면 된다.

```
reel-scenes.json ─→ 타임라인 IR ─┬─→ Remotion → mp4 (자동 발행)
                                 └─→ 캡컷 드래프트 → 소장님이 손편집
```

작업 순서는 이렇게 된다.

1. 제가 드래프트 폴더를 만들어 전달(압축 파일 또는 소장님 PC에서 실행하는 스크립트)
2. 소장님이 캡컷을 열면 그 프로젝트가 목록에 보임
3. 컷 타이밍·자막 위치를 손보고 캡컷에서 내보내기
4. (선택) 손보신 결과를 다시 읽어 자동 생성 기본값에 반영 — **되먹임**

4번이 실은 가장 값어치가 크다. 소장님이 "이 자막은 좀 늦게 떠야 한다"고 손보시면,
그 감각이 다음 주 자동 생성분에 반영된다.

### 암호화면 → 후퇴안 (B안)

캡컷을 조종하는 건 포기하고, **재료를 먹기 좋게 잘라 드리는** 쪽으로 간다.

- 씬별 클립 mp4 (자막 없는 깨끗한 배경)
- 자막 PNG (투명 배경) 또는 SRT 자막 파일
- 폰트·컬러 값 안내
- 씬 순서·타이밍 표

캡컷에서 **끌어다 놓기만 하면 되는 상태**로 폴더를 만들어 드린다.
"에이전트가 직접 편집"은 아니지만, 조립 시간은 크게 줄어든다.

## 미리 아셔야 할 제약 3가지

이건 평문이어서 연동이 되더라도 남는 한계다.

**1. 드래프트는 소장님 PC 안에만 있다.**
자동화는 클라우드 서버(리눅스)에서 도는데, 거기서 드래프트를 만들어봐야 열 사람이 없다.
그래서 실제 운영은 둘 중 하나가 된다.
- 폴더를 압축해 소장님께 전달 → 압축을 풀어 드래프트 폴더에 넣기
- 소장님 PC에서 실행하는 작은 스크립트를 드리기

**2. 발행 파이프라인 밖에 둔다.**
비공식 포맷이라 캡컷 업데이트에 **예고 없이 깨질 수 있다.** 매일 도는 자동 발행이
여기에 묶여 있으면 캡컷 업데이트 한 번에 그날 콘텐츠가 통째로 없어진다.
그래서 캡컷 경로는 **"필요할 때 따로 뽑는 기능"** 으로 둔다. 자동 발행은 지금처럼 Remotion 이 계속한다.

**3. 내보내기는 윈도우 캡컷이 필요할 수 있다.**
드래프트 생성 도구들이 "생성한 드래프트는 윈도우판 캡컷에서 내보내야 한다"고 명시한다.
맥에서 쓰신다면 이 부분을 파일럿 때 같이 확인해야 한다.
