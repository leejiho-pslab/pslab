# pslab SNS 자동화 솔루션 — 설계도

> 이 문서는 전문 용어 없이, **비유**로 전체 구조를 설명합니다.
> 목표: **사람이 거의 손대지 않고(95%→100%) 알아서 돌아가는 SNS 콘텐츠 공장**을 만들어
> 여러 클라이언트에게 **공장 한 대씩 복제해 납품**하는 것.

---

## 0. 한 장 요약

- **무엇**: 주제만 정하면 글·이미지·영상을 알아서 만들고, 여러 SNS에 알아서 올리고, 성적표까지 알아서 보내주는 자동 시스템.
- **대상 SNS**: 유튜브 · 네이버 블로그 · 인스타그램 · 스레드 · 링크드인
- **핵심 가치**: 사람의 일을 **"매일 글쓰고 올리기" → "가끔 OK만 누르기" → "아예 안 보기(100%)"** 로 줄인다.
- **사업 모델**: 공장을 잘 만든 뒤 **클라이언트마다 설정표 한 장**만 갈아 끼워 빠르게 납품.

---

## 1. 큰 그림 — 끝이 처음으로 이어지는 자동 컨베이어 벨트 🏭

원료(소재)가 들어가면 벨트를 타고 흘러가 완성품(게시물)이 나오고,
배달까지 끝나면 성적표가 다시 맨 앞으로 돌아와 **"다음엔 뭘 만들지"** 를 알려줍니다.
그래서 **쓰면 쓸수록 똑똑해지는** 둥근 벨트입니다.

```
        ┌───────────────────── 다시 처음으로 (학습) ─────────────────────┐
        │                                                                │
        ▼                                                                │
  ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
  │ 1.소재   │ → │ 2.제작   │ → │ 3.검수   │ → │ 4.발송   │ → │ 5.성적표 │
  │   수집   │   │  (글/   │   │ (사람5%, │   │ (여러SNS │   │  (자동   │
  │          │   │ 그림/   │   │  나중엔  │   │  동시)   │   │  보고)   │
  │          │   │ 영상)   │   │  끔)     │   │          │   │          │
  └──────────┘   └──────────┘   └──────────┘   └──────────┘   └──────────┘
     자동           자동          반자동→자동      자동           자동
```

## 2. 6개 작업소 상세 (각 단계가 무슨 일을 하나)

### 1️⃣ 소재 수집소 — "오늘 뭐 올릴지 알아서 정함"
- **하는 일**: 요즘 뜨는 키워드·뉴스·트렌드를 자동으로 긁어와 후보 소재를 만든다.
- **재료**: 클라이언트의 업종/관심 주제 (설정표에 적힌 것)
- **결과**: "오늘의 소재 후보" 목록
- **사람 개입**: 없음 (자동)

### 2️⃣ 콘텐츠 제작 공장 — "글·그림·영상을 찍어냄"
- **하는 일**: 소재로 글을 쓰고, 어울리는 이미지·썸네일·(필요시)영상을 만들고, 해시태그를 달고, **클라이언트 말투에 맞춰** 다듬는다.
- **재료**: 소재 + 클라이언트 브랜드 말투/금지어 (설정표)
- **결과**: 바로 올릴 수 있는 완성 게시물
- **사람 개입**: 없음 (자동)

### 3️⃣ 품질 검사대 — **여기가 그 '5%'** 👀
- **하는 일**: 올리기 직전 사람이 한 번 슥 보고 OK.
- **중요**: 이 단계는 **스위치**다. 켜면 사람이 보고(안전), **끄면 통과(100% 자동).**
- **계획**: 초기엔 켜서 신뢰를 쌓고, 안정되면 **클라이언트별로 하나씩 꺼서 완전 자동**으로 전환.
- **사람 개입**: 처음엔 OK 한 번 → 이후 0

### 4️⃣ 발송 센터 — "여러 SNS에 동시 배달"
- **하는 일**: 반응 좋은 시간대에 맞춰 5개 SNS에 한꺼번에 자동 게시.
- **재료**: 완성 게시물 + 클라이언트 계정 출입증 + 발송 시간표
- **결과**: 각 SNS에 게시 완료 + 게시 주소
- **사람 개입**: 없음 (자동)

### 5️⃣ 성적표실 — "결과를 알아서 정리해 보고"
- **하는 일**: 조회수·좋아요·댓글을 모아 표로 만들고, **클라이언트에게 자동 발송**(메일/메신저).
- **재료**: 게시 주소들
- **결과**: 주간/월간 성적표
- **사람 개입**: 없음 (자동)

### 6️⃣ 학습실 — "잘된 걸 기억해 더 잘함" (벨트가 1번으로 복귀)
- **하는 일**: 어떤 글이 반응 좋았는지 분석해 다음 소재 추천에 반영.
- **결과**: 더 똑똑해진 1번 소재 수집소
- **사람 개입**: 없음 (자동)

## 3. 클라이언트 납품 구조 — "공장 한 대씩 복제" 🏭🏭🏭

여러 회사에 파는 게 목표이므로:

- **공장(벨트)은 똑같이 하나만 잘 만들어 둔다.**
- 클라이언트마다 **"설정표 한 장"** 만 갈아 끼우면 그 회사 전용 라인이 가동된다.
- 각 클라이언트 정보는 **각자 잠긴 서랍**에 따로 보관 → A사·B사 내용이 절대 섞이지 않음.
- **새 클라이언트 받기 = 설정표 작성 → 라인 가동.** (이게 납품 속도의 핵심)

### 클라이언트 설정표(한 장) 예시
```
회사 이름      : OO카페
업종/주제      : 디저트, 신메뉴, 지역 맛집
브랜드 말투    : 친근하고 따뜻하게, 이모지 적당히
금지어         : (경쟁사명), 과장 표현
올릴 SNS       : 인스타그램, 네이버 블로그, 스레드
발송 시간      : 매일 오전 11시, 오후 7시
검수 스위치    : 처음엔 [켬] → 한 달 뒤 [끔]
계정 출입증    : (각 SNS 연결 열쇠) ← 잠긴 서랍에 보관
성적표 받을 곳 : 사장님 카톡 / 이메일
```
> 새 클라이언트는 **이 표만 채우면 끝.** 공장 내부는 손대지 않는다.

## 4. 95% → 100% 자동으로 가는 길 🔁

| 단계 | 사람이 하는 일 | 자동화율 |
|------|----------------|----------|
| 도입 초기 | 게시 전 OK 누르기 + 클라이언트 설정 | 약 90% |
| 안정기 | 가끔 성적표 보고 방향만 조정 | 약 95% |
| 완전 자동 | **검수 스위치 끔** → 사실상 안 봄 | 99%+ |

핵심은 **검수 스위치 하나로 사람의 개입을 0에 수렴**시키는 것.
처음부터 100%로 켜지 말고, **신뢰가 쌓이는 만큼 클라이언트별로 끈다.**

## 5. 진짜 자동을 굴리는 3대 필수 장치 ⚙️

지금까지 만든 건 "리허설"이고, 무인 운영을 하려면 이 3개가 더 필요하다.

1. **24시간 안 꺼지는 관리인 (상주 직원)**
   지금은 "실행!" 명령해야 한 번 돈다. 진짜 자동은 **아무도 없어도 새벽에 알아서 게시**돼야 하므로, 늘 대기하는 관리인이 필요.

2. **고장 알림벨 (경비 시스템)**
   계정 연결이 끊기거나 오류가 나면 **즉시 알림.** 안 그러면 며칠째 안 올라가는 걸 모를 수 있다.

3. **관제실 상황판 (한눈에 보는 화면)**
   어떤 클라이언트 글이 올라갔고, 뭐가 대기 중이고, 성적이 어떤지 **한 화면에서** 보고, **클라이언트에게도** 보여주면 신뢰 상승.

## 6. 구축 순서(로드맵) — 무리하지 않게 4단계로

> 큰 공장을 한 번에 짓지 않고, 매 단계마다 **돌아가는 결과물**을 본다.

- **1단계 — 자동 골대 세우기**
  "항상 켜진 관리인" + "클라이언트별 잠긴 서랍" 구조. → 무인으로 예약·발송이 도는 뼈대.
- **2단계 — 제작 공장 진짜로 가동**
  AI로 글·이미지·썸네일을 실제로 생성해 붙인다.
- **3단계 — 성적표 + 학습실**
  성적 자동 수집·발송, 잘된 콘텐츠를 다음 소재에 반영.
- **4단계 — 관제실 + 검수 스위치**
  상황판 화면과 클라이언트별 검수 켬/끔 → 납품·운영 완성, 100% 자동 전환.

## 7. 지금 상태 vs 목표

| 작업소 | 지금 | 목표 |
|--------|------|------|
| 소재 수집 | 수동(주제 입력) | 자동 수집 |
| 콘텐츠 제작 | 자동 틀(임시 글) | AI 글·이미지·영상 |
| 검수 | 자동 통과/실패 검증만 | 켬/끔 스위치 |
| 발송 | **됨**(리허설) | 24시간 무인 발송 |
| 성적표 | **됨**(표 출력) | 자동 발송 |
| 학습 | 없음 | 잘된 콘텐츠 반영 |
| 클라이언트 복제 | 없음 | 설정표 1장으로 추가 |
| 관리인/알림/상황판 | 없음 | 추가 |

> **요약**: 벨트의 "흐름"은 이미 한 바퀴 돌려봤고(리허설 성공), 이제 **무인으로 24시간 돌아가게 + 클라이언트마다 복제 + AI 제작을 진짜로** 채워 넣는 일이 남았다.
