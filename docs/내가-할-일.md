# 회원님이 꼭 하셔야 하는 일 (모닝 체크리스트)

> 주무시는 동안 제가 할 수 있는 **소프트웨어 뼈대는 전부 만들어** 두었습니다.
> (설계도의 모든 작업소가 mock으로 한 바퀴 돕니다 — `npm run autopilot` 로 확인 가능)
>
> 이제 남은 건 거의 다 **"제가 만질 수 없는, 회원님만 하실 수 있는 일"** 입니다.
> 크게 3종류예요: **① 결정 ② 열쇠(키·계정) 발급 ③ 운영 판단.**
> 아래 순서대로만 하시면 됩니다. **★ 표시가 가장 급한 것**입니다.

---

## 한눈에: 왜 이건 제가 못 하나요?

비유하면, 저는 **공장과 컨베이어 벨트를 다 지어** 놨어요.
그런데 **각 SNS의 정문 열쇠(계정 출입증)** 와 **AI 도구의 전기(API 키)** 는
회원님 명의·결제·본인인증이 있어야만 발급됩니다. 이건 법적으로도 제가 대신 못 해요.
열쇠만 주시면, 그걸 꽂는 작업(코드 연결)은 다시 제가 합니다.

---

## ① 결정만 하면 되는 것 (5~10분, 키 불필요)

이건 회원님 머릿속 결정이라 제가 대신 못 합니다. 답만 주시면 제가 설정표에 반영해요.

- [ ] **첫 클라이언트가 누구인가** (내 회사? 시범 고객 1곳?)
- [ ] **업종 / 핵심 주제 키워드** 5~10개
- [ ] **벤치마킹할 경쟁사 계정** 2~5곳 (이름/핸들)
- [ ] **브랜드 말투** (예: 친근/전문/유머) 와 **금지어**
- [ ] **올릴 SNS** (유튜브·블로그·인스타·스레드·링크드인 중 선택)
- [ ] **검수 스위치 시작값**: 처음엔 `manual`(직접 승인) 추천

> 👉 이 답들은 `clients/demo-cafe.example.json` 형식의 **설정표 한 장**이 됩니다.
> 말로 주셔도 제가 JSON으로 만들어 드려요.

---

## ② 열쇠 발급 — 가장 중요하고 유일한 진짜 병목 ★

각 항목은 **그 계정의 주인(회원님/클라이언트)** 만 발급할 수 있어요.
**하나라도 주시면** 그 채널부터 바로 실제 발행으로 연결합니다.

### A. SNS 발행 출입증 (실제 게시에 필수) ★
| SNS | 회원님이 발급할 것 | 어디서 |
|-----|-------------------|--------|
| 인스타그램/스레드 | Meta 앱 생성 → 액세스 토큰, 사용자 ID | developers.facebook.com (비즈니스 계정 필요) |
| 유튜브 | Google Cloud 프로젝트 → OAuth 클라이언트, 리프레시 토큰, 채널 ID | console.cloud.google.com |
| 네이버 블로그 | 네이버 오픈API 앱 → 클라이언트 ID/시크릿, 액세스 토큰 | developers.naver.com |
| 링크드인 | LinkedIn 개발자 앱 → 액세스 토큰, author URN | developer.linkedin.com |

> 발급한 값은 `.env` 파일에 `PSLAB_<플랫폼>_<키>=...` 형식으로 넣습니다
> (`.env.example`에 빈칸 양식 있음). **채팅에 키를 그대로 붙여넣지 마세요** — 노출 위험.
> 값 이름만 알려주시면 어디에 넣는지 제가 정확히 안내합니다.

### B. AI 제작 도구 키 (콘텐츠 품질용)
- [ ] **글 생성**: Claude API 키 (텍스트 품질의 핵심)
- [ ] **이미지/영상 생성**: 이미지·영상 생성 서비스 키 (썸네일·릴스용)

> 없어도 시스템은 **템플릿 글 + 플레이스홀더 이미지**로 돕니다.
> 키를 주시면 제가 프로바이더를 코드에 꽂아 실제 AI 생성으로 바꿔요.

### C. 알림 받을 곳 (선택)
- [ ] **Slack 웹훅 URL** 또는 **이메일** — 발행 실패/승인 대기 알림을 받을 곳.

---

## ③ 운영 중 회원님 역할 (가동 후, 매일/매주)

- [ ] **(초기) 검수 승인** — `manual` 모드일 때 올라가기 전 게시물에 OK.
      처음엔 매일, 신뢰 쌓이면 횟수↓
- [ ] **검수 스위치 전환 판단** — "이 클라이언트는 믿을 만하다" 싶으면
      `manual → rules → auto` 로 단계 격상 (이건 신뢰 판단이라 회원님 몫)
- [ ] **AI 회의 결론 점검** — 주간 성적표에 붙는 "다음 방향"이 사업 감각과 맞는지 확인
- [ ] **무인 가동 인프라 결정** — 24시간 자동으로 돌리려면 **항상 켜진 서버**가 필요.
      어디서 돌릴지(클라우드/자체 서버)와 결제는 회원님 계정이라야 합니다.
      **"어디서 돌릴지" 결정만** 주시면, 그 위에서 도는 **상주 데몬 코드는 제가 작성**합니다.

---

## 그래서 제가 다음에 할 수 있는 일 (회원님 입력 대기 중)

회원님이 위 ①②를 주시는 만큼, 제가 이어서 만들 수 있습니다:

1. **설정표 확정** → ①의 답을 받으면 `clients/<회사>.json` 생성
2. **채널 실연결** → ②-A 키를 받으면 해당 플러그인의 mock을 실제 API 호출로 교체
3. **AI 생성 연결** → ②-B 키를 받으면 글·이미지 생성 프로바이더 주입
4. **알림 연결** → ②-C를 받으면 Slack/이메일 싱크 추가
5. **상주 데몬(관리인)** → ③의 인프라 결정 후, 24시간 자동 트리거 작성
6. **상황판 화면** → 그다음 단계로 진행

---

## 우선순위 요약 (딱 3가지만 기억)

1. **★ ②-A SNS 출입증 하나라도** — 이게 있어야 "진짜 발행"이 됩니다 (최대 병목)
2. **① 설정표 답** — 5분이면 끝, 첫 클라이언트가 굴러갑니다
3. **③ 무인 인프라 결정** — 어디서 24시간 돌릴지

> 이 셋 중 **무엇이든 먼저 주시는 것부터** 제가 바로 이어서 연결하겠습니다.
> 일어나시면 편하게 "①부터 하자" / "인스타 키 받았어" 처럼 알려주시면 됩니다. 🙂
