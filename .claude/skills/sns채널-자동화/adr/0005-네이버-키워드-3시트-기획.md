# ADR-0005: 네이버 검색광고 키워드도구 기반 3시트 기획

- **상태**: 채택됨
- **날짜**: 2026-07-16
- **관련 SKILL**: §5
- **관련 ADR**: ADR-0006

## 맥락 (Context)
블로그(네이버·구글) 기획의 소재 선정이 감(感)에 의존해 검색 유입 정확도가 낮았다. 초기엔
데이터랩 **상대지수**만 썼는데, 상대값이라 절대 규모를 몰라 우선순위를 못 정했다. 실제
**월간검색수**가 필요했다.

## 결정 (Decision)
`scripts/fetch-keywords.mjs`가 **네이버 검색광고 API `/keywordstool`**(HMAC-SHA256 서명)로
시드 키워드의 월간검색수(PC/모바일)·경쟁정도와 검색량 상위 연관어를 받아 `keyword-trends.json`
**v3**로 저장한다. 3시트 구조 — `core`(핵심), `related`(연관), `timely`(시의성=월별 시즌 시드)
각 **검색량 상위 20** + `baseDate`(기준일). 워크플로 **금요일 게이트**로 주1회 갱신(기준일 고정).
대시보드가 3시트를 표로 렌더하고, **블로그 소재는 검색량 상위 키워드 우선**으로 기획한다.

## 고려한 대안 (Options)
- **A안(채택) — 검색광고 keywordstool 월간검색수 3시트**: 실제 절대 검색량 + 연관어 발굴.
  단점: 시크릿 3종·HMAC 서명 관리, 광고계정 필요.
- **B안 — 데이터랩 상대지수(구버전 v1/v2)**: 키 간단. 단점: 상대값이라 규모 판단 불가(폴백으로만 유지).
- **C안 — 수동 키워드 리서치**: 유연. 단점: 무인 자동화·주간 갱신과 안 맞음.

## 결과 (Consequences)
- (+) 기획이 실측 검색수 기반이 되고, 검색량 낮은 소재를 걸러낸다.
- (+) 연관어 자동 발굴로 소재 풀이 넓어진다.
- (−) `NAVER_AD_API_KEY`/`NAVER_AD_SECRET`/`NAVER_AD_CUSTOMER_ID` 관리와 서명 로직 유지 필요.
- (−) 프리미엄 상품군은 검색량이 낮아, 제목은 고검색 키워드로 후킹하고 본문에서 전문성으로 전환하는 설계가 필요.

## 관련 파일
`scripts/fetch-keywords.mjs`, `data/clients/<id>/keyword-trends.json`, `src/core/dashboard.ts`(blogSection)
