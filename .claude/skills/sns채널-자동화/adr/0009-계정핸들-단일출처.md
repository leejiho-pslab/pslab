# ADR-0009: 계정 핸들은 client 설정을 단일 출처로 통일한다

- **상태**: 채택됨
- **날짜**: 2026-07-16
- **관련 SKILL**: §2
- **관련 ADR**: —

## 맥락 (Context)
동성특수인쇄의 인스타 핸들이 전화번호 기반 오기(`dongsp5771`)로 렌더러·유튜브 설명·마감장표·
대시보드에 **하드코딩되어 산재**했다. 실제 공식 계정은 `@dongsp_official`. 하드코딩이 여러
파일에 흩어져, 한 곳만 고치면 다른 콘텐츠에 옛 핸들이 그대로 나가는 위험이 있었다.

## 결정 (Decision)
브랜드 식별자(계정 핸들·링크)는 **`clients/<id>.json`의 `accounts`/`channelLinks`를 단일
출처**로 삼는다. 이번엔 산재한 하드코딩 값(`dongsp5771` → `dongsp_official`)을 전 파일에서
정정하고, 인스타·스레드·URL을 한 값으로 통일했다. 변경 후 **CI 재렌더 + 라이브 대시보드
검증**으로 전 콘텐츠 반영을 확인한다. 향후 렌더러는 하드코딩 대신 client 설정을 참조하도록
리팩터할 여지를 남긴다.

## 고려한 대안 (Options)
- **A안(채택) — client 설정 단일 출처 + 산재 하드코딩 일괄 정정**: 근본 원칙 확립 + 즉시 정정.
  단점: 현재 일부 렌더러가 여전히 하드코딩(후속 리팩터 과제로 명시).
- **B안 — 틀린 곳만 그때그때 수정**: 빠름. 단점: 재발(다른 파일에 옛 값 잔존) — 이번에 실제로 발생.

## 결과 (Consequences)
- (+) 전 채널·콘텐츠·대시보드의 핸들이 한 값으로 일관.
- (+) 교훈 확립: **브랜드 식별자는 하드코딩 금지, 설정 참조**.
- (−) 렌더러의 남은 하드코딩을 설정 참조로 바꾸는 리팩터가 후속 과제로 남는다.

## 관련 파일
`clients/dongsung.json`(accounts/channelLinks), `scripts/render-*.mjs`, `scripts/ig-outro.mjs`,
`scripts/seed-youtube-meta.mjs`
