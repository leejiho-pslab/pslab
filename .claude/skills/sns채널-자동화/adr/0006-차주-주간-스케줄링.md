# ADR-0006: 차주 주간 스케줄링 (금 수집 → 토 기획)

- **상태**: 채택됨
- **날짜**: 2026-07-16
- **관련 SKILL**: §5
- **관련 ADR**: ADR-0005

## 맥락 (Context)
키워드(ADR-0005)를 실제 **주간 콘텐츠 캘린더**로 자동 연결하고 싶었다. 단, 라이브 발행
데이터(`plan.json`)를 자동으로 건드리면 검수 전 콘텐츠가 실수로 나갈 위험이 있었다.

## 결정 (Decision)
`scripts/plan-week.mjs`가 **토요일**에 검색량 상위 키워드로 다음주(월~일) 콘텐츠 기획안
(채널·날짜·제안 제목·시트구분)을 만들어 **`week-plan.json`**에 저장한다. `plan.json`은
**건드리지 않는다**. 대시보드 "📅 차주 콘텐츠 기획" 패널에 표시하고, 실제 제작은 이 기획안을
기준으로 **감도·가짜글자 검수(ADR-0003/0004)를 거친 뒤** 진행한다. 시의성 키워드는 주 1회 배치.
흐름: **금요일 키워드 수집(ADR-0005) → 토요일 차주 기획 → (검수 후 제작) → 매일 18:00 발행.**

## 고려한 대안 (Options)
- **A안(채택) — 별도 week-plan.json + 수동 제작 게이트**: 라이브 plan과 분리돼 안전, 검수 개입 보장.
  단점: 기획안 → 실제작이 자동이 아니라 한 단계 수동.
- **B안 — plan.json에 바로 다음주 항목 생성**: 완전 자동. 단점: 미검수 콘텐츠 자동발행 위험(치명적).

## 결과 (Consequences)
- (+) 키워드가 주간 기획으로 자동 연결되면서도 라이브 발행은 안전하게 분리된다.
- (+) 감도·가짜글자 검수 게이트가 파이프라인에 구조적으로 들어간다.
- (−) 기획안을 실제 콘텐츠로 옮기는 제작·검수는 수동으로 착수해야 한다.

## 관련 파일
`scripts/plan-week.mjs`, `data/clients/<id>/week-plan.json`, `.github/workflows/pslab-cron.yml`(토요일 게이트)
