# ADR-0003: 인스타 이미지-전면형 에디토리얼 디자인 시스템

- **상태**: 채택됨
- **날짜**: 2026-07-16
- **관련 SKILL**: §5
- **관련 ADR**: ADR-0001, ADR-0004

## 맥락 (Context)
초기 카드뉴스는 정보 전달은 됐으나 감도(브랜드 인상)가 아쉬웠다. 프리미엄 패키지 업종은
피드의 첫인상이 곧 신뢰라, 감성 레퍼런스 계정처럼 "사진 + 절제된 타이틀" 전면형이 필요했다.

## 결정 (Decision)
`render-ig.mjs`에 **이미지 전면형** 렌더를 두고, 통일된 디자인 시스템을 코드화한다:
- **3스타일**(`cinema`/`photoA`/`photoB`) — 레이아웃·폰트무게·강조 방식만 다르게 해 피드에 리듬.
- **통일 팔레트**(3~5색, 강조색 1개만) + **명조 세리프 디스플레이**(`@fontsource/nanum-myeongjo`를
  npm으로 받아 woff2를 `assets/fonts`에 base64 번들) + 산세리프 본문.
- **넓은 여백·슬라이드당 12단어 이내**, **커버 후킹 공식**(볼드 6~10자 + 큐리오시티 갭).
- 규칙은 `data/clients/<id>/ig-design-spec.md`(감도 규칙서)에 적어 렌더러·이미지 프롬프트가 따르게.
- plan 항목에 `slidePhotos`+`igStyle`을 주면 이 렌더러가 처리하고, `render-cards.mjs`는
  `slidePhotos` 가진 인스타 항목을 자동 제외.

## 고려한 대안 (Options)
- **A안(채택) — 전면 사진 + HTML 타이틀 오버레이, 3스타일 통일 시스템**: 감도·일관성 모두 확보.
  단점: 슬라이드마다 신규 이미지 생성·검수 비용.
- **B안 — 텍스트 카드뉴스 유지**: 제작 단순. 단점: 감도 낮아 프리미엄 포지셔닝과 불일치.
- **C안 — 스타일 매 게시물 자유**: 다양성↑. 단점: 브랜드 일관성 붕괴, 피드가 산만.

## 결과 (Consequences)
- (+) 피드 감도·브랜드 일관성이 오르고, 스타일 혼합으로 지루함을 피한다.
- (−) 콘텐츠마다 이미지 신규 생성·감도 검수가 필요(재사용 금지).
- (−) 개발환경 403으로 최종 합성 이미지를 못 볼 수 있어 검수 경로(네트워크 허용/캡처)가 필요.

## 관련 파일
`scripts/render-ig.mjs`, `scripts/ig-outro.mjs`, `data/clients/<id>/ig-design-spec.md`
